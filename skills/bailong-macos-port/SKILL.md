# 白龙桌宠Swift 维护

## 工作入口

1. 核对目标工作区、分支、未提交改动和 [VERSION](../../VERSION)。按 [AGENTS.md](../../AGENTS.md) 执行本次授权范围内的操作。
2. 按任务阅读[现行架构](../../docs/来源与架构.md#现行行为约束)，从[源码入口](../../docs/来源与架构.md#source-map)定位状态持有者、显示组件及调用方。界面改动按项目规则使用 `macos-golden-gate-design`。
3. 需要对照原作行为时，仅查阅相邻 Python 工程 `../bailong-desktop-pet` 在 `v0.5.1 / b102e73` 的对应实现。

## 修改与核对

- 气泡和历史优先共用显示组件。涉及回复、插话或审批时，先定位内置或外部会话的发送入口，再核对会话、轮次、请求和窗口身份。[会话与任务](../../docs/来源与架构.md#current-tasks)
- 项目问卷按通信方式核对入口。新版气泡跳转到出题的原会话，旧版普通问卷在气泡内答题。人设问卷由独立 app-server 处理。排查原窗口缺少消息时，先核对发送入口选中的会话及轮次归属。[会话与任务](../../docs/来源与架构.md#current-tasks)
- 排查项目会话发送时，先查桌面端版本建议和已保存的手动选择。新版主动发送先打开目标原会话，再走桌面队列。旧版回复与同轮插话走 IPC。用目标线程的入队回执结束提交，用观察器的轮次状态判断执行和结束。回归检查覆盖下一条草稿、非当前会话跳转、执行中插话入口和结束后解锁；仅入队结果不明时要求手动核对。[会话与任务](../../docs/来源与架构.md#current-tasks)
- 新版项目命令审批用受信任项目的 `PermissionRequest`（`Bash`）复验允许、拒绝、转到 Codex 三种结果。在临时项目核对会话、轮次与原请求连接。旧版沿用 owner 快照和 IPC 审批，人设审批归独立 app-server。[会话与任务](../../docs/来源与架构.md#current-tasks)
- 设置项变更同时核对静态搜索、默认值、导入导出和恢复范围。修改表单公用回调时，检查设置首页、搜索打开的管理页及主题页调用方。[设置与个性](../../docs/来源与架构.md#current-settings)
- 动画改动按解码、目标流交接、图层呈现和几何位移定位。性能记录注明画质、帧率、帧缓冲配置和所用机型。[动画与吸边](../../docs/来源与架构.md#current-animation)
