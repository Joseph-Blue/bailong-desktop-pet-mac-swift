# 设置页面检查（0.6.0-dev.10）

依据：项目 bailong-macos-port 与 macos-golden-gate-design；本次按源码检查全部 9 个设置分类，未打开应用或自动截图。

窗口结构：贯穿侧栏、系统工具栏与搜索、右侧滚动正文；正文最大 780pt。保留用户指定的浅底语义分组，不新增装饰外框。玻璃位于系统侧栏／工具栏及独立预览，正文使用普通背景。

| 分类 | 检查与处理 |
| --- | --- |
| 通用 | 原生启动操作和显示器菜单；保留状态副标题，首次窗口填充与已有位置恢复分开处理。 |
| 称呼与个性 | 变量、默认正文、计数与编辑保持原行为；状态及互动台词仍按语义分组。 |
| 动作与活动 | 鼠标绑定共用宽度，滑块操作区对齐；组级说明缩为 4pt 间距。 |
| 消息与提醒 | 三个进展开关置于互动台词下方；历史记录／审批说明并入紧凑副标题，快捷键长说明保留全宽；索引同步。 |
| 外观 | 宽高比、材质说明归入对应控件；手动玻璃开关补辅助功能名称，版本说明与 macOS 26 起的代码门控一致。 |
| 高级 | 清空本应用的本机数据：设置项／按钮／确认框／搜索同名；保留红色危险操作、二次确认及回车不执行规则。 |
| 性能 | 画质、帧率、缓冲、预加载顺序及统一轨道宽度保留；预加载下缓冲禁用逻辑保留。 |
| 更新 | 保留原生操作与真实检查状态；状态说明缩短上方间距，未发起更新查询或改偏好。 |
| 关于 | 保留图标、版本、架构与原生分页；致谢改名并加入可直达对应分页的搜索入口。 |

缩放与可访问性：保留原生焦点、系统语义色、既有减少透明度／动态效果处理；窗口填充沿用可用区域，不进入独立全屏空间。

待用户运行验收：深浅模式、窄窗口换行、首次填充及绿灯恢复、已保存位置召回、搜索跳转、缩放及辅助功能实际朗读。静态检查与编译不记作上述运行验收。

验证：最终 dev.10 Apple Silicon 主程序／helper 编译、本地签名及索引／文案定向静态核对通过。
