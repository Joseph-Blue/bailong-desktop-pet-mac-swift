# 开发分支维护

## 分支职责

`joseph/dev` 是独立开发线，远端跟踪 `origin/joseph/dev`。`main` 保留正式版源码、README 和精简 CHANGELOG。GitHub 默认分支仍为 main。

开发在 joseph/dev 提交并推送。不自动合并 main，不变基、不强推已归档历史。正式版需要某项开发改动时，按授权选择对应提交并整理正式版说明；开发分支的 README、完整 CHANGELOG、待办和跟踪规则留在开发线。主线修复进入开发线也须明确选择或合并，不自动覆盖开发文档。

## 文档与文件跟踪

开发线额外跟踪 todo.md、开发分支说明、历史变更索引、启动闪退调查、设置界面检查、开发资源获取说明和[搜索与消息内存审计](搜索与消息内存审计.md)。完整原始 CHANGELOG 保存在 Git 历史，索引链接到具体提交。

内存审计保留源码持有关系、缓存边界、合成样例结果与后续问题；原始采样、进程信息和逐步实施流水留在本机。

本机实施流水、未经整理的草稿、.vscode、本机配置、用户数据、素材及构建产物仍不跟踪。新增公开开发文档时，先整理内容，再将具体文件加入 .gitignore 白名单。

历史调查中的路径、工具和结论以当时版本为准；当前实现见来源与架构及源码。

## 版本与交付

源码版本使用 SemVer 预发布后缀：开发阶段为 dev，候选阶段为 rc；初始版本为 0.6.3-dev.1，当前为 0.7.4-dev.3。该分支发布 Git 源码、文档及独立开发资源，不发布开发版可执行程序或应用版本标签。资源包经授权使用 dev-assets-* 标签创建 Pre-release，显式设置非 Latest，仅上传资源 ZIP。

更新程序请求 releases/latest，并校验 draft=false、prerelease=false、版本号无预发布后缀。它不读取开发分支的 VERSION，开发版本号高于正式版不会进入普通用户的更新提示。

本次没有构建或运行应用；仅检查提交历史覆盖、文档差异和远端分支结果。
