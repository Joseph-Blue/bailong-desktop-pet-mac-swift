# 0.1.0-dev.1 实施记录

日期：2026-10-29。目标：从零实现 Swift + AppKit 原生白龙桌宠，原 WebM + FFmpeg。独立 Git 工程，不覆盖原作者仓库和旧 Mac 工程。

## 已实施

- 创建 Swift 工程、AGENTS、独立 SemVer 版本和中文 changelog。
- 原生透明桌宠、后台 RGBA 解码、首帧展示与载入面板、时间轴播放、alpha 命中与透明留白穿透、菜单栏与原生菜单。
- 拖拽、落地、左右吸边/展开、自移动和闲置/工作动作、尺寸设置、音效、任务气泡与显隐开关。
- 原生对话和可滚动历史、任务目录选择、角色提示词、流式输出与公开摘要、步骤、结果、审批与补充提问、真实停止、额度文本与进度条显示。
- 只读外部任务同步：公开字段投影、工具错误/等待提示、通知去重与间隔提醒、初始旧完成任务过滤、活动轮次继续追踪、多活动任务计数。
- 独立历史格式与原子保存；单实例锁及唤回、全屏判断、睡眠唤醒、退出回收、用户选择启用的 LaunchAgent。
- 构建包含原素材和 arm64 FFmpeg 的本地 .app。

## 本轮证据

- xcrun swift 显示本机 Apple Swift 6.4、arm64 工具链。
- Swift 源码通过 swiftc 编译，目标 arm64-apple-macosx14.0。
- scripts/build.sh 成功生成 dist/白龙桌宠.app，并完成本地 ad-hoc 签名。
- 依据编译诊断修正 NSObject 方法名冲突；静态阅读修正拖拽计时、隐藏时审批父窗口、气泡定位、尺寸关闭提交、对话跟随位置、应用内键鼠互动计时和退出回复顺序。
- 没有启动桌宠、发送模型请求、启用 LaunchAgent、执行上游自检、截图、视觉或哈希校验。
