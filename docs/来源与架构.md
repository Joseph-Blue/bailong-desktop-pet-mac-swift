# 来源与架构

本文描述 **0.7.4** 的现行实现。正式版变化见 [CHANGELOG](../CHANGELOG.md)，完整开发迭代与撤回记录保留在 [joseph/dev](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/tree/joseph/dev)。

## 技术与源码职责

应用使用 Swift + AppKit，最低运行系统为 macOS 14；液态玻璃使用 macOS 26 起的原生能力。源码保持单个 Swift target，`scripts/swift-sources.sh` 递归收集主程序源码，跟随助手独立编译并与主程序架构一致。

| 层次 | 实现与入口（相对 Sources/BailongPet） |
| --- | --- |
| 启动与桌宠 | `App/` 管理生命周期；`Pet/Pet.swift` 管理动作、窗口、菜单、拖拽及吸边 |
| 动画 | `Pet/Resources.swift`、`StreamingAnimation.swift` 使用 AVAssetReader；`CPUFrameConverter.swift` 使用 vImage 缩放与转换颜色 |
| 会话 | `Conversation/ChatController.swift` 管理内置连接；`DesktopConversationSession.swift` 管理外部会话明确提交 |
| 外部观察 | `Codex/DesktopHistoryReader.swift` 只读 SQLite；`DesktopSync.swift` 合并轮次，`DesktopRuntimeProjection.swift` 保留目标轮次公开进展 |
| 用户消息 | `Codex/UserInputText.swift` 整理附件包装；`UI/Shared/MarkdownText.swift` 共用气泡与历史排版 |

## 素材与播放

运行素材为 35 段透明 HEVC MOV。0.7.4 沿用 0.7.3 正式 App 的整套 MOV 与素材清单，不重新转换或接入后续试修素材。当前这套文件制作于 2026-10-31，其中 idle／idle2 来自当时的修边平滑 PNG，landing 来自落地修复 PNG，drag 最后接入龙角及卷发缺块恢复版。前三段各 96 帧／24 fps／4 秒，落地 48 帧／24 fps／2 秒，母版尺寸均为 720×720。

播放链为 HEVC Alpha → AVAssetReader BGRA → CPU／vImage → RGBA CGImage → AppKit。转换器读取源颜色空间和 Alpha 模式；缩放时转换为线性 sRGB 预乘浮点像素，用 Lanczos 缩放并约束透明边缘过冲，再转回 sRGB 预乘 RGBA8。原尺寸直接转换，不分配浮点缩放缓冲。工作区按当前动画复用，每帧输出由 CGDataProvider 独占并负责释放。

PNG 接入工具仍使用 Core Image、AVAssetWriter ProRes 4444 和系统 avconvert，见 [原生素材工具](../Tools/NativeHEVC/README.md)。原始 WebM／PNG、修复副本及中间文件留在 local-assets，不打包或进 Git；应用不包含 FFmpeg 或 Python／PySide6 运行时。

新用户默认较高 512×512、12 帧缓冲、满帧，已有设置保留。另有 720、384、256 三档，缓冲范围 6～240；非法输入结束编辑时恢复 12。满帧按实际素材帧率与播放速度调度，当前 33 段 24 fps、2 段 30 fps，另可限为 20 或 15 FPS。整段预加载默认关闭；开启仅完整加载当前动作，不预热素材库。

流式读取在串行后台队列运行，按视频 PTS 消费，缓冲满时暂停读取；切换与回绕通过身份标记丢弃过期结果。素材选帧与位置／旋转 displayLink 分离，屏幕刷新不增加解码请求。几何动画仅活动期间运行，隐藏或结束暂停。

“轮廓阴影”默认开启，沿用 AppKit `NSWindow.hasShadow`，绘制帧后调用 `invalidateShadow()` 更新窗口阴影；不改素材像素、不增加描边位图。用户反馈部分动作开启阴影时会出现少量底部马赛克，可关闭该选项。

## 动作选择

默认普通待机 idle／idle2 按 4:1，吸边按 7:3 抽选。任务中先排除上一动作及关闭动作，再按工作／待机 35:65 选择非空组，组内默认均匀；只有一个候选组时选择该组。保留手动频率和偏爱，按场景基础权重成比例调整。若只启用当前一段，继续默认待机。

每段播放结束后才选择下一动作；任务不会缩短素材时长。“减少重复动作”用于其他随机互动、额外动作和移动，普通待机与吸边按各自权重选择。开场、任务成功庆祝、拖拽、落地和额度动作保留事件触发规则。自主活动间隔控制额外动作与移动，不是基本待机循环的停顿时长。

## 会话与消息

内置人设对话由独立 CodexConnection 管理，沿用同连接已加载会话身份；外部 Codex 项目会话使用原桌面端通道，发送保留模型、思考档位与权限，不附加桌宠人格。人设与项目共享显示组件，发送通道和生命周期分别管理；人设会话没有开放执行中发送。跨端 writer 自动交接仍未实现。

外部回复使用 start-turn，执行中插话使用 steer-turn；回执核对原会话与轮次，超时保留草稿及待确认状态，不自动重发。只有真实 completed 才宣告成功，缺少助手正文不以用户提问或会话标题回填。

`UserInputText` 识别 Files mentioned／My request 附件包装，处理前导空白与 CRLF，显示实际提问与紧凑本机文件入口，不读取图片载荷。只有识别到包装时才移除对应重复图片占位。SQL 读取有界文本及附件计数，整条问卷回执排除；显示层重复整理不截断已生成链接。

气泡和历史共用 `MarkdownText.renderUserInput`，保留换行和链接，不将用户正文解析为放大的标题。`ChatController.showUserMessage` 共用接收卡片；插话按真实 userMessage ID 合并，原 IPC 回执不重复造卡，不触发新任务开场。插话统一读取 taskSteeringTemplate，默认“{用户名}，补充的话我收到啦，我会记着一起处理。”；ConversationLines 同步生成设置、搜索、恢复与导入导出范围。

卡片按身份原地更新，待处理请求优先；用户浏览旧卡或填写问卷时不自动切卡。倒计时、卡片状态与正文视图分别管理。气泡位置随桌宠移动，跨屏和尺寸变化按可用区域避让。

进展只显示公开 reasoning.summary 与工具结构化字段，不保留原始思考或工具原始输出。工具调用短气泡按实际 TextKit 排版与正文空间截断，追加 `...`，不提供正文滚动；完整 hover 与原始进展数据保留。思考摘要及普通气泡保留原滚动规则。标题动效、盲文和秒表只在显示层生成，隐藏或任务结束停止。

久无进展提醒默认开启、间隔 5 分钟，可设 1～30 分钟，同时要求至少 90 秒没有公开进展；复用已有同步节拍。等待回答／批准、停止、隐藏、安静模式及输入期间让位。

敏感问题仅跳转或使用对应安全输入入口，不在桌宠历史保存答案。审批默认拒绝，明确操作前核对原请求及任务身份；审批回执不修改后来出现的新表单。停止与进程回收保留原任务边界。

## 历史、文件和输入

历史使用 SQLite schema 3，启动只加载元数据，正文按需读取；缓存最多 16 条、合计 2 MiB，每页 20 轮。旧 JSON 首次事务迁移后保留原件。关闭历史释放显示缓存，保留草稿及选择。

关闭历史记录时冻结快照，重新开启不补录关闭期间内容。损坏或未知格式保持只读，保存失败暂停自动写入并提供显式重试。外部旧记录只在当前页补缺失用户输入，核对页请求、记录身份、冻结状态和开关，不全库扫描或新增轮询。

Markdown、图片及产物引用共用文件链接处理，本机文件点击通过固定 Finder 自动化脚本复用目标目录窗口并选中文件；`.app` 只定位。网页链接交给系统，裸 http(s)／mailto 地址在非代码区域补充链接属性。手形光标问题仍保留在开发分支待办，不作为 0.7.4 已修复项目。

文件修改摘要统计本轮已完成修改，不代表最终 Git 净差异；默认展示 3 项，目录为次级灰、文件名与展开／收起为正文色、增减为绿／红。历史搜索可展开隐藏匹配项；不保存原始 diff，不提供撤销操作。

临时输入、历史回复及问卷共用 MessageEditor／MessageInputBox，保留中文组字保护和用户发送快捷键。草稿按入口及会话独立保存，晚到回执不清空后来选择的草稿。

## 设置、系统集成与性能

设置和历史使用 AppKit 原生分栏、工具栏及搜索。设置条目变化同时维护 SettingsSearchEntry 与实际定位锚点，不为建索引创建页面或触发预览。液态玻璃只影响背景，正文与输入保持独立；减少透明度时使用实色。

强调色预设来自用户截图取样；原生控件通过公开 contentFilters 映射颜色，跟随系统时不加滤镜。危险／警告保持语义色。

性能窗口关闭即停止统计，区分应用运行内存 (RAM)、GPU 资源组与系统 Swap；像素估算不是进程实测。降低默认缓冲和改用 CPU 处理不等于最低配置机器或长时运行已完成验收。

数据目录为 `~/Library/Application Support/BailongPetAppKit`，设置使用独立配置域。更新检查通过 URLSession 读取公开正式 Release，不读取 dev 分支版本，不自动安装；启动检查默认关闭。额度每次重新请求，不用旧结果代替新查询。

登录／跟随启动只维护用户已启用项，不自动为新用户注册；跟随仅识别 Codex／ChatGPT 桌面应用。拒绝 AppTranslocation 临时路径，不读凭证或改全局 Codex 配置。应用完整退出清理连接与子进程，界面关闭与应用退出分别处理。

## 构建与交付

根目录 VERSION 是应用和工具版本来源。`scripts/build.sh arm64` 与 `x86_64` 分别构建主程序和同架构跟随助手，输出 `dist/native-hevc/<VERSION>/<架构>/白龙桌宠Swift.app`；只复制运行素材，不包含 WebM、PNG、ProRes 中间文件或用户数据。`run-dev.sh --build-only` 只生成开发可执行文件。

正式分发采用 Apple Silicon ZIP 与 Intel 社区测试 ZIP；Intel 尚未经过 Intel Mac 实机验收。应用本地签名，未做 Apple 公证。发布说明与正式 CHANGELOG 分别整理相较上一个正式 Release 的最终变化，开发试验、原始调查与实施流水留在开发分支或本机。
