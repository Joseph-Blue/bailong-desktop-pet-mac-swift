<a id="current-bubble"></a>
### 气泡与显示

- **滚动视口与行宽（`BubbleBodyScrollView`／`BubbleBodyLayout`）**：统一计算正文排版宽度，左右边距对称（默认 `21pt` 随气泡比例缩放，小比例下至少容纳系统滚动条轨道加 `2pt` 间距）。纵向滚动条占用右侧边距，`lineFragmentPadding = 0`，滚动条显隐与窗口尺寸过渡均不改变文本换行宽度；仅内容纵向溢出时启用原生滚动条。多行阅读与输入容器关闭横向弹性并固定 `x = 0`，可滚动纵向区域启用 AppKit 原生边缘回弹（不滚动的短进展气泡除外）。
- **增量排版与首行稳定（`MessageTextView`）**：共用单一 TextKit 容器完成高度测量与显示，更新时保留未变化前缀、仅替换变化尾部。无用户选区时写入正文后将插入点保持在 `{0, 0}`，并拦截容器 `setFrameSize` 期间的自动 `scrollToVisible`，防止任务信息栏异步挂载或窗口伸缩把视口拉向文末。`BubbleBodyScrollView` 固定 `documentView` 原点为 `.zero`，按 `BubbleMotion` 落地的目标视口高度判定纵向溢出。普通气泡打开、切卡与正文变更时在原生 clip／document 布局完成后执行单次回顶；用户开始滚轮或拖动滚动条即取消待执行回顶，后续排版保持当前阅读位置（新开或切卡后忽略此前残留的触控板惯性滚轮，直至产生新的滚动手势；外观配色刷新保留阅读位置列于 TODO）。
- **2 秒短进展气泡**：正文优先显示与主进展／任务概览相同的组摘要，保留个性台词标题与单次操作公开细节；相同摘要与细节合并为一条。同一轮次仅保存最近呈现的台词、正文与图标状态，内容不变时不重弹、不重置停留时间，任务结束或停止观察时释放；正在尝试重连的结构化状态绕过去重，继续走原连接状态提示入口。固定采用内容自然高度，不套自定义宽高比，摘要为空时不预留正文区（结构化命令项为空时回退至同项公开 `command` 摘要）。文本按真实视口在字素边界截断并追加 `...`，专用 clip 锁定顶部原点并屏蔽滚轮偏移，悬停提示复用同一份有界摘要。
- **卡片栈与停留计时（`BubbleCardStore`／`BubbleCountdown`）**：卡片保留上限为 `5～100`（默认 `20`），近期结束任务数为 `1～20`（默认 `5`），展示优先级依次为“待处理审批或问卷 ＞ 任务消息 ＞ 任务概览或互动台词”。用户手动翻阅或填写问卷期间不自动切卡，同条流式消息原地更新，已处理请求自动移除；额度结果、设置预览与普通动作对白不写入卡片栈。单卡固定显示 `1 / 1` 并置灰翻页箭头；鼠标移入暂停倒计时、移出续计，翻页重新计时，审批、问卷与错误卡片保持常驻直至用户手动处理。
- **任务概览与互动触发**：仅鼠标动作设为 `random`（“显示任务进度、播放随机动画”）时展示并复用单张 `taskOverview` 卡片，每次触发刷新工作中台词与会话最新轮次列表并移至栈尾；`randomAnimation`、菜单随机动画与设置动作试播只播放动画和单句台词。助手消息卡按真实消息 ID 区分，不跨轮次合并。
- **四向定位与刘海过渡（`BubblePlacement`）**：气泡与输入窗随桌宠拖动实时跟随，动作切换与吸边不主动收起气泡。普通状态优先桌宠下方或上方，刘海收纳状态下的大气泡按“左、右、下、上”顺序避让屏幕边界与输入窗；位于下方时固定上边缘向下伸展，位于上方时固定下边缘向上伸展。在 `0.3s` 刘海收纳／展开过渡期内，气泡锚点按收纳与展开两端的可见轮廓线性插值（复用 `dockProgress`），不跟随 `180°` 旋转过程中的外接矩形起伏。
- **状态图标、计时器与文字动效**：
  - `InlineStatusLayout` 对齐文字基线与图标大写字高中心，加载盲文按完整 `⣿` 字形单元固定槽位；等待用户审批或回答时隐藏执行盲文并继续保留任务计时。
  - `TaskActivitySymbolView` 在默认比例下为主进展／概览采用 `15pt`、短进展／待处理标题采用至少 `16pt` 的 `.semibold` 等宽高槽位图标；失败、拒绝、取消／中断分别在操作图标旁附加语义色状态角标。
  - 右上角秒表按任务真实开始时间每秒刷新（`MM:SS`／`H:MM:SS`），外部任务结束优先取 `completed_at`；完成定格为绿色，失败／取消／中断定格为红色。
  - `ProgressTextEffects` 标题扫光周期为 `1.2s` 扫过＋`2.8s` 停顿，保留不透明黑／白底字，浅色黑字扫亮灰、深色白字扫暗灰；峰值向白／黑混合 30%，系统开启“增加对比度”时降至 18%，不扫至纯白／纯黑。扫光按 16 档离散高亮缓存属性字典原型，`2.8s` 停顿期直接复用整段底色属性，避免逐帧新建浮点 `NSColor` 污染 UIFoundation 全局弱属性字典表。`ProgressMarqueeView` 仅在标题超宽时以 `28pt/s` 循环滚动，首尾以带留白的 `·` 衔接，同文刷新保留相位。隐藏、销毁、任务结束或开启“减少动态效果”／关闭“动态效果”时停止计时器。
- **窗口动效、退出与玻璃材质**：
  - `BubbleMotion` 默认开启：出现 `160ms` 淡入＋`4pt` 位移、关闭 `120ms`、高度伸缩 `140ms`、材质切换 `160ms`。尺寸变化先完成玻璃容器布局，再按窗口实际落地尺寸排版正文视口。菜单与信号退出先在常规 RunLoop 完成淡出、停止任务与保存数据后再调用 `NSApp.terminate`；系统关机等直接进入 `terminateLater` 的路径同步向 `.modalPanel` 注册过渡计时器。
  - macOS 26+ 默认使用单窗口 `NSGlassEffectView.contentView` 承载正文与衬底（支持跟随系统 `regular` 或手动 `clear`＋`0～1` 不透明度；开启“减少透明度”或 macOS 14～15 自动使用普通实色背景，切换材质保留原响应者且不激活应用）。
  - 主气泡、短进展、预览、临时输入与工作区状态条在启用玻璃材质时共用 1 物理像素的 `GlassEdgeHighlight` 内侧渐变亮边（顶部较亮、侧边渐弱，不响应鼠标、不叠加于原生 `NSPopover`）。气泡显示底部 Git／文件信息栏时底边距收紧为 `8pt`（正文与按钮区上下各留 `4pt`），无信息栏时保持 `16pt`。

### 输入与窗口

- **气泡任务信息栏 vs 独立工作区状态条**：
  - 气泡内的「任务信息栏」（`taskInfoBarEnabled`，默认开启）位于正文下方、底部操作按钮上方，复用 `WorkspaceStatusView` 单行展示 Git 仓库状态与本轮文件增删（隐藏目录名；干净 Git 仓库照常显示，非 Git 目录且无本轮文件改动时隐藏）。同会话主气泡已展示状态行时，2 秒短进展气泡自动去重；任务概览行仅受该开关控制是否显示对应轮次的文件增删统计。
  - 独立的「工作区状态条」（`WorkspaceStatusPanel`，由 `gitWindowEnabled` 控制，默认关闭）采用不可成为 key 的 `PetWindow`（`allowsInput = false`，全空间跟随且不参与窗口循环），只设**常驻显示**与**隐藏**两种状态。右键菜单与状态栏菜单项根据当前状态动态显示「显示工作区状态条」／「隐藏工作区状态条」，点击状态条左侧关闭按钮同样将 `gitWindowEnabled` 置为 `false`。面板单行排列关闭按钮、目录／仓库名、Git 状态与本轮文件统计（最大宽度 `640pt`，优先排在桌宠下方，空间不足转上方）；桌宠隐藏时暂隐并在桌宠恢复时按开关状态还原，关闭开关即停止后台 Git 查询与文件监听。
- **Git 状态查询与文件监听（`GitWorkspaceRequest`）**：面板可见时通过 `/usr/bin/git --no-optional-locks -C <cwd>` 只读解析 `porcelain=v2 -z` 状态及分支／上游信息（单命令超时 `8s`、输出上限 `8 MiB`，不启动登录 shell、不执行 `fetch`、不改动索引）。对 Git 工作树与实际 `.git`／`commondir` 建立 `FSEvents` 递归监听，经 `400ms` 防抖合并查询，查询期间的新事件合并补查一次；非 Git 目录及隐藏／关闭状态下不驻留监听器。
- **Git 状态标识与详情弹窗（`WorkspaceFileTable`）**：上游或唯一远端为 `github.com` 时显示 Primer Octicons GitHub 图标，其余仓库显示 Lucide `git-branch` 图标（HTTP(S) 剔除用户信息，主流代码托管 SSH 地址映射为网页链接）。紧凑状态使用等宽半粗字体：绿色 `+N` 已暂存、橙色 `!N` 未暂存、蓝色 `?N` 未跟踪、红色 `~N` 冲突、紫色 `*N` 暂存栈、绿色 `✓` 工作区干净、蓝色 `⇡N / ⇣N` 上游提交差。本轮文件改动统计读取所属轮次已完成的 `Turn.fileEdits`（`+N −N`）。Git 详情与文件详情共用原生透明列表 Popover（应用内外非锚点点击经 `PopoverDismissal` 自动收起，显式聚焦标准窗口前同步关闭；单击选中、双击在访达中定位、右键支持访达定位与拷贝完整路径）。
- **非激活输入与会话草稿（`ChatComposer`／`ChatNavigation`）**：
  - 临时输入面板采用 `.nonactivatingPanel`，`ContentCursorPanel` 将 `⌘X`／`⌘C`／`⌘V`／`⌘A` 直接路由至面板内当前第一响应文本视图，不依赖前台应用菜单栏。
  - 显式打开设置时收起临时输入面板；面板挂有审批／问卷等附属 sheet 时保留宿主，供用户继续处理。
  - 临时输入、历史回复与气泡问卷共用 `MessageEditor`／`MessageInputBox`（`NSBox` 与焦点框同级挂载于共同父视图后再激活约束）及 `SendShortcut`（`⌘↩`、`↩`、`⌃↩ 或 ⌘↩`，完整保护中文输入法组字状态，快捷键提示置于发送／确认按钮悬停提示）。
  - `ChatNavigation` 与 `ChatDraftCache` 按入口（临时输入／历史窗口）和会话分别保存内存草稿，异步发送回执核对原目标身份，不会清空用户随后切换到的会话草稿。
  - 临时输入窗顶部采用原生分段控件切换人设／项目对话，会话选择器同行右对齐；执行状态与短错误信息优先与模型选择器同行排布（模型摘要保底宽度 `max(120pt, 10 × 字号)`），超宽或多行报错独立成行并在 `96pt` 高度上限内纵向滚动。
- **窗口与 Dock 生命周期（`InterfaceWindows`）**：仅登记未关闭的标准窗口（设置默认 `1040×900pt`、正文上限 `780pt`；历史初始 `1100×850pt`；点击绿灯填满当前屏幕可用区域，不进入独立全屏空间）。存在打开或最小化的标准窗口时保留 Dock 图标，全部关闭后自动收回 Dock 图标；显式打开、Dock 图标召回与最小化缩略图恢复统一经 `InterfaceWindows.focus` 先收起非激活面板浮层、解除最小化并无条件执行 `NSApp.activate(ignoringOtherApps: true)` 与下一轮主队列前台／key 复核（防止非激活面板置位 `NSApp.isActive` 导致跳过真实应用激活），后台刷新不召回窗口。`⌘Q` 或 Dock 退出仅关闭当前标准窗口，彻底退出桌宠通过右键／状态栏／应用菜单触发。再次启动应用会主动召回隐藏或吸边的桌宠。文件选择面板（`PanelPresentation`）与取色板（`CenteredColorWell`）首次打开时在当前屏幕居中一次，后续允许自由拖动；`HoverHelp` 悬停延迟 `200ms`、淡出 `80ms`。

### 会话与任务

- **双通道隔离**：
  - **内置人设会话**：由 `ChatController` 管理独立 `codex app-server --listen stdio://` 子进程，连接内复用已加载线程身份，按轮携带所选模型、推理档位与桌宠人设指令，由 `TaskMessageAccumulator` 聚合公开事件。
  - **外部项目会话**：`DesktopHistoryReader` 与 `DesktopSync` 只读投影桌面端 SQLite 与实时状态；`DesktopConversationSession` 负责模型设置读取、轮次回复（`thread-follower-start-turn` v2）、执行中插话（`steer-turn` v1）与待确认状态跟踪，完全沿用原会话配置，不注入桌宠人设。后台状态同步不激活 Codex 窗口。
- **外部发送的热路径与冷启动衔接**：
  - **桌面端已就绪（热路径）**：若已缓存有效会话设置则直接建立 IPC 连接提交，否则先触发一次原会话路由再连接（单次连接上限 `2s`、重试间隔 `250ms`、总窗口 `20s`）。
  - **桌面端未运行或刚启动不足 10 秒（冷启动路径）**：保存原请求、会话、轮次与原文进入准备态。针对桌面端冷启动账户确认阶段替换初始主窗会清空首窗待发路由的问题，仅在桌面端存活且尚未发现 owner 时，于 `2.5s`、`7.5s`、`14s` 后台静默补投递 `codex://threads/<id>`（`activates = false`），一旦连上或用户点击“取消发送”立即停止。主动准备循环与被动 `5s` 节流的 `refreshSettings` 解耦：单次 `thread-owner-discovery` 上限 `1.5s`、间隔 `250ms`、总窗口 `60s`；等待期间收到目标会话的 `thread-stream-following-status-requested` 或带变更的 `thread-stream-state-changed` 广播时，在同一连接立即重发发现请求，成功后同连接读取模型设置并直接提交。
  - **防重发边界**：真实 `start-turn`／`steer-turn` 发出后若连接中断或回执超时，会话转入 `Unconfirmed`（待确认）并保留原文草稿，不自动重发，也不改由内置 `app-server` 接管。
- **桌面 IPC 套接字（`DesktopSocket`）**：在请求等待与广播监听两条路径上对 `client-discovery-request` 统一应答 `canHandle = false`，其余未知请求返回 `no-handler-for-request`；请求帧 `timeoutMs` 与分片 `poll` 等待严格收敛于当前调用剩余期限。
- **审批与问答（`RequestCoordinator`）**：审批默认动作为拒绝，气泡审批按钮不绑定回车或键盘允许快捷键（左右顺序仅作用于气泡）。外部审批解析兼容 `thread-stream-state-changed` v11～v13（增量补丁校验同源连接与相同协议版本），提交允许前二次核对 owner、请求 ID、轮次与非空命令详情。标记为敏感的提问仅提供“转到 Codex”入口，不在桌宠展示题面或保存答案；普通多题问卷支持逐题切换与跳过，按问题 ID 保留草稿并仅提交非空答复。
- **公开进展投影与分组（`TaskActivity`）**：
  - 仅提取公开 `reasoning.summary` 与工具结构化字段（`commandActions`、`tool`、`namespace`、`server`、`changes` 等）。多行 shell 命令仅取首行命令与参数并标记省略，单次最多展示 3 条（每条 120 字）。
  - 主气泡工具栏、任务概览及短进展气泡共用 `TaskActivity.groupActivity` 的组摘要，按客户端分组语义折叠连续工具调用（`reasoning` 不断组，助手消息与独立展示项构成组边界，消息边界清空前序思考标题）；短气泡另保留当前操作的公开细节和个性台词。

### 历史与数据

- **存储格式与容错迁移**：偏好设置使用独立域 `com.bailongpet.appkit.settings.v2`（首次启动定向迁移旧域已知键并保留原数据）。历史库采用 SQLite schema 3（`~/Library/Application Support/BailongPetAppKit/history.sqlite`），首次读取旧版 JSON schema 1／2 时在事务内完成迁移并保留原 JSON 备份；若遇数据库损坏、更高版本 schema 或磁盘写入失败，自动进入只读保护模式并提供原库导出与重新加载，不以空库覆盖用户数据。
- **按需加载与记录冻结**：开启记录历史（默认开启）时，内存仅常驻会话与轮次元数据，正文通过最多 `16` 条／`2 MiB` 的 LRU 缓存按需从 SQLite 读取；历史窗口每页固定展示 `20` 轮，翻页替换渲染结果，关闭窗口时清空正文、TextKit 排版与搜索缓存。关闭记录历史期间冻结磁盘快照，停止写入且重新开启后不补录关闭期间的对话。
- **会话排序、重命名与删除**：会话标题优先同步 `threads.name`（未生成前按 `5s` 节流补查，用户手动重命名后固定保留本地名称直至主动恢复同步），列表按真实最新消息或轮次起止时间倒序排列。工具栏右侧 `trash` 按钮与右键菜单共用无默认回车的删除确认：内置运行中会话先停止任务再在事务内删除记录并登记防回填 ID；外部会话仅移除桌宠侧记录与同步订阅，不影响 Codex 桌面端原会话。
- **全文搜索与当页补缺**：历史工具栏内置原生搜索框（`⌘F` 聚焦，`⌘G`／`⇧⌘G` 跳转上下处匹配），支持跨会话正文摘要筛选与当页高亮定位（命中折叠文件列表时自动展开）。首次进入或重开历史窗口定位至底端，同会话刷新保持当前滚动位置，显式搜索跳转优先。外部会话缺失早期用户输入文本时，仅对当前可见页按需读取补齐（遵守记录冻结与只读边界）。
- **轮次标题与底栏渲染（`TranscriptRenderer`／`TranscriptActionBar`）**：用户与桌宠发言标题分别前置系统人物图标与 `petAvatarTemplate`，名称与时间使用应用强调色；本轮文件修改摘要在 `turn.finished` 后渲染于正文下方。每轮底栏左侧展示完成状态与真实 `completedAt`（缺失标“未提供”），中部通过独立解耦的 `TokenDisclosureControl` 展示 `本轮 / <数量> / Tokens`（首行与左侧状态文字基线对齐，箭头墨迹中心对齐大写字高光学中心，悬停文字或箭头呈现统一圆角高亮框，点击展开自有 TextKit 对齐的输入／缓存命中／输出明细），右侧提供仅复制助手正文的拷贝按钮与“转到 Codex”按钮。
- **异常恢复面板（`Recovery`）**：覆盖启动资源检查、历史库读写与首段动画加载异常，提供可滚动的错误详情拷贝、局部重试与新建 Issue 链接，不安装全局信号吞错器，也不在诊断文本中拼接对话正文或凭证信息。

<a id="current-animation"></a>
### 动画与吸边

- **解码管线与无缝交接**：角色动画共 35 段透明 HEVC `.mov`（33 段 `24 fps`、2 段移动素材 `30 fps`），经 `AVAssetReader` 解出 BGRA 帧后由 `CPUFrameConverter`（`vImage`）完成线性光缩放与色彩转换，交由 `SpriteView` 的 `CALayer.contents` 直接呈现 `CGImage`（仅图像身份、绘制区域、几何变换、刘海裁切或屏幕 `backingScale` 实际变化时提交图层属性，关闭 Core Animation 隐式动画）。切换动作时仅取消未完成的后台加载任务并递增 `generation`，旧动作持续供帧，待新动作准备好首帧及约 `250ms` 可播放余量（整段预加载模式则待全段就绪）且代次有效后再原子切换画面与时间轴。按下桌宠期间不暂停选帧，落地动作等待后续指令期间保持末帧。
- **画质、帧率与缓冲参数**：新用户默认采用流式播放、`512×512`（较高）、`12` 帧缓冲（可设 `6～240`，非法输入失焦恢复 `12`）与“满帧”档位。画质提供 `自动`、`原画 720`、`较高 512`、`中 384`、`低 256`（`自动` 按 `角色逻辑尺寸 × 动作 renderScale × 屏幕 backingScale` 选取最小足够档位）；帧率上限提供 `满帧`、`20 FPS`、`15 FPS`（流式限帧在色彩转换前按源 PTS 抽样以节省缩放与遮罩开销，动作总时长不变）。开启“整段动画预加载”（默认关闭）时，缓冲帧数与开头缓存自动置灰并保留原值。
- **画质与性能增强项**：
  - **动作平滑过渡**（`animationSmoothTransition`，默认开启）：非同动作且非吸边几何动画交接时，在统一逻辑画布上按 `64×64` 网格采样旧末帧与新首帧 Alpha 加权重合度；重合度 `≥ 90%` 时向图像图层提交 `180ms` `CATransition.fade`（遵守“动态效果”与系统“减少动态效果”）。
  - **孤立杂点清理**（`animationEdgeCleanup`，默认开启）：在生成预乘 RGBA8 后剔除八连通分量内全部像素 `Alpha ≤ 16/255` 且面积不超过阈值（`256／384／512／720` 档对应 `1／2／4／8` 像素）的游离噪点，毗邻主体或柔边的像素逐字节保留。
  - **常用动作开头缓存**（`animationOpeningCache`，默认开启）：对已播放的常用待机、拖拽、落地与额度动作缓存前 `6` 帧图像及 Alpha 命中遮罩，LRU 总上限严格控制在 `24 MiB` 运行内存 (RAM) 以内；命中后即刻满足起播并由后台按相同相位续读后续帧。
  - **轮廓阴影**（`petShadow`，默认关闭）：控制桌宠窗口 `NSWindow.hasShadow` 并在图层更新后刷新透明轮廓阴影（偶发黑点问题列于 TODO 排查）。
- **调度计时与动作权重**：素材选帧使用单次 `Timer` 锚定动作时间轴（容许 `1µs` 浮点误差，回调晚到不顺延下一帧基准）；桌宠可见且已加载动画期间持有单份 `.userInitiatedAllowingIdleSystemSleep` 活动断言，在可见播放期间保持应用活动（不阻止显示器或系统空闲休眠，手动隐藏、全屏自动隐藏、系统睡眠或退出时立即释放）；窗口位移与旋转缩放使用 macOS 14+ `NSView.displayLink` 跟随当前屏幕刷新率，静止或隐藏时立即挂起。随机池默认比例为：普通待机 `4:1`、吸边待机 `7:3`、任务执行中先排除上一动作再按 `35:65` 抽取工作组／待机组；用户可在 `0～12` 之间调节单段动作 ❤️ 权重（默认待机保底为 `1`）。仅额度查询加载期间（`quotaLoading`）暂停自主活动；首次启动完成首段加载后播放一次 `01` 问候动作（已有活动任务或打开面板时跳过）。
- **左右边缘吸边、刘海收纳与多显示器**：
  - 左右边缘吸边与顶部刘海吸边独立开关，露出比例范围均为 `40%～85%`（步进 `5%`，默认 `55%`）；吸边状态下按 `250ms` 区分单击召回与双击查额度，拖动直接召回。
  - 刘海位置通过内建显示器 `safeAreaInsets.top` 与左右 `auxiliaryTopLeftArea`／`auxiliaryTopRightArea` 实时计算，拖入顶部 `24pt` 触发区后旋转 `180°` 倒挂贴合；无刘海屏幕自动忽略顶部收纳并保持左右吸边可用。位置记忆始终保存展开态安全坐标（初始默认位于屏幕可用区横向 `85%`、距底边 `23%`）。
  - `preferredDisplay` 为空时允许跨屏自由拖动；指定显示器后将桌宠移动与拖动范围约束在该屏幕内，外接屏断开时临时回退至可用屏幕并在重连后自动归位。
- **性能统计窗口与采集口径（`Diagnostics`）**：默认关闭，仅在窗口打开期间每秒采样并差量刷新界面，关闭窗口即刻停止计时器（支持左上角置顶 Pin 与“拷贝完整诊断”）：
  - **更新 FPS**：统计 `SpriteView` 每秒向图层提交的不同 `CGImage` 帧数（纯几何位移不计入帧率；完整诊断另附含几何更新的图层提交总次数与最长帧间隔）。
  - **CPU**：基于 `getrusage` 进程累计 CPU 时间差分；界面总体占比除以逻辑核心总数，完整诊断附加单核满载 `100%` 基准值。
  - **GPU**：基于 `PROC_PIDCOALITIONINFO`（`coalition_info_resource_usage.gpu_time`）差分，反映当前应用进程组（含子进程）的 GPU 时间占比。
  - **运行内存 (RAM) 与 Swap**：运行内存取 `TASK_VM_INFO.phys_footprint`（完整诊断附 `compressed` 压缩内存及去重后的驻留帧像素字节数；`512×512` 下 12 帧缓冲队列像素与遮罩约占 `15 MiB`，`720×720` 约 `29.7 MiB`）；系统交换空间取 `vm.swapusage`，本进程累计换入量取 `ledger_swapins`。

  - 首行标题区分 `ChatGPT 免费用户`（Free）、`ChatGPT 订阅 · <套餐名>` 与 `计费方式 · <名称>`；Business 体系按公开 `planType` 精细区分 `Business Standard`（`team`／`business`）、`Business Premium`（`self_serve_business_prolite`）与 `Business 按量计费`（`self_serve_business_usage_based`），且当 `account/read` 返回具体子档时优先于 `rateLimits` 的粗粒度标记。
  - Free 与 Go 账号仅展示单条 `30 天额度`（无可用重置卡且无点数余额时省略空重置卡行）；Plus、Pro、Business Standard 等多窗口套餐展示 `5 小时额度` 与 `每周额度`，剩余比例 `≤ 10%` 标橙色、`≤ 5%` 标红色。
  - 额度气泡内说明文字、缓存时间戳、日志副标题及展开明细统一采用高对比正文色 `labelColor`；重置时间采用 `12.5pt` 半粗等宽数字字体，后接真实 `\t` 与 `NSTextTab` 右侧对齐倒计时（如 `7 小时 32 分钟`，不足 1 分钟显示 `< 1 分钟`），气泡最小排版宽度随重置行实测宽度自适应以避免折行。重置卡张数与到期明细下附小字可用点数说明；底栏同行放置订阅管理网页入口与带 `arrow.clockwise` 图标的强调色「立即刷新」按钮（失败态显示「重试」）。
- **可选额度缓存**：`quotaCacheEnabled` 默认关闭；开启后仅在运行内存 (RAM) 缓存最近一次成功的额度结果（`quotaCacheSeconds` 默认 `60s`，范围 `15～300s`，不落盘）。命中缓存前先通过轻量 `account/read(refreshToken: false)` 校验当前账号身份，若账号切换、连接重建、到达任一窗口重置时刻或超过缓存有效期则自动重新请求；点击「立即刷新」直接跳过缓存。缓存命中时界面注明 `缓存 · 更新于 <时间>`。
- **Token 用量统计与统一展开控件（`TokenDisclosureControl`）**：
  - **本轮用量**：取会话累计 Token 快照的当轮增量（`cachedInput` 已包含在 `input` 内，不重复累加至 `total`；内置会话监听 `thread/tokenUsage/updated`，外部会话在轮次结束后按日志偏移读取公开 `token_count`）。
  - **今日用量（本机日志）**：查询额度时在后台按本机时区增量扫描当前 `CODEX_HOME` 日志文件（跨日自动归零、自动去重分叉事件，即使额度命中缓存也实时刷新本机日志增量）。
  - **统一交互控件**：额度弹窗、历史底栏与任务完成气泡底栏全部复用 `TokenDisclosureControl`。常态无外框，鼠标悬停文字或箭头的任意位置时绘制整块圆角高亮背景，点击整块区域切换展开／收起，右键支持拷贝汇总文本；展开后的 `输入 / 缓存命中 / 输出` 明细使用独立 TextKit 视图（`TranscriptTokenText`）与真实 `NSTextTab` 对齐三列并支持自由划选复制。

### 文件与产物

- **Git 详情弹窗排版**：按“分支与远端摘要 → 冲突／已暂存／未暂存／未跟踪分组列表”纵向组织。工作区路径可通过 `WorkspaceLinkButton` 一键在访达打开，远端展示精简 `owner/repo` 并保留完整 URL 悬停提示。分组标题首组高 `22pt`、后续组高 `30pt`（含组间上留白），文件行高 `26pt`；文件行左侧突出显示文件名，次级目录置于同行并以较小正文色优先截断，右侧固定展示修改状态码。手动或自动刷新期间保持弹窗开启并锁定外部锚点尺寸，结果更新后保留列表滚动位置与原选中项。
- **文件引用与访达定位（`CodexFileCitation`／`FinderFileReveal`）**：`MarkdownText` 在代码块、行内代码与已有超链接之外解析 `:codex-file-citation{path="..."}` 产物标记、普通本地文件链接及公开 `imageGeneration.savedPath`，相对路径基于所属会话 `cwd` 解析并在用户点击时校验存在性（`sandbox:` 链接给出受限沙盒说明，网页链接交由系统默认浏览器打开）。定位本地文件时通过参数化脚本优先复用已打开的目标目录访达窗口、取消最小化并选中目标文件（`.app` 包仅在访达选中而不启动执行，不恢复其他无关最小化窗口）。
- **本轮文件修改摘要与代码块**：`FileEditSummary` 汇总当轮已完成的 `fileChange`（同路径多次修改按轮次合并，增删行数按全文或 diff hunk 累计，单独持久化于 `Turn.fileEdits`，不保存原始 diff 文本）。`FileEditRendering` 在气泡和历史正文下方默认展示前 3 个文件并支持展开／收起，搜索命中折叠项时自动展开。Markdown 代码块采用原生 `NSTextTableBlock` 绘制边框与底色，顶部语言栏与 `HoverIconButton` 拷贝按钮共用 `CodeBlockHeaderLayout` 与 `CopyFeedback`。

<a id="current-build"></a>
### 构建与集成

- **构建入口与增量缓存**：根目录 `build.command` 与 `run-dev.command` 共用 `scripts/swift-environment.sh`、`scripts/swift-sources.sh` 与 `scripts/resource-manifest.json`。脚本根据当前 SDK 自动启用 `full`（27+）、`glass`（26+）或 `plain`（14+）编译条件，并将 `SDKROOT` 透传给主程序与跟随启动 helper 的编译链接流程。`run-dev.command` 的增量缓存同时校验源码列表、文件时间戳、SDK 版本、编译器版本与档位参数。
- **正式版更新检查（`Updates`）**：默认关闭启动自动检查；手动或自动检查均创建独立 `URLSession`（直接沿用系统 HTTP／HTTPS／PAC 代理与 TUN 路由配置）请求公开仓库 `releases/latest` API（请求超时 `20s`、资源超时 `30s`），按 SemVer 比较版本。单次检查超过 `8s` 显示慢速提示与取消按钮；网络或限流失败时在窗口内分级展示具体原因并提供可折叠拷贝的技术详情（自动检查失败仅静默记录于设置页）。自动检查发现新版弹出的非抢焦提示窗额外提供「😡 不许打扰我，禁用自动更新检查」快捷关闭按钮。
- **登录自启与随 Codex 启动（`Autostart`／`FollowMonitor`）**：仅维护用户主动开启的启动项，应用路径或版本变化时自动更新注册信息，用户从系统设置撤销许可后保持关闭状态不强行重装，运行于 `AppTranslocation` 临时只读路径时拒绝绑定启动项。跟随启动由同架构独立 helper 监听桌面端 Codex／ChatGPT 应用进程生命周期（不监听命令行 `codex`）；后台串行卸载旧服务并注册新服务，遇 `launchd` bootstrap 错误码 `5` 时延迟 `1s` 重试一次。
- **默认工作区与本机数据清理**：默认工作区留空时使用 `~/Library/Application Support/BailongPetAppKit/Workspace`；点击“清理内置工作区”仅将该根目录下的直接子项移入系统废纸篓（不跟随符号链接，不影响聊天历史，有任务运行或发送中时拒绝清理；用户指定自定义目录时隐藏该清理按钮）。设置高级页分别提供“清空磁盘缓存”与“清空本应用的本机数据”两项独立确认操作。
