# 来源与架构

## 源码依据

作者仓库：../bailong-desktop-pet，v0.5.1，提交 b102e734f20bb50889af12df5778f1499109f41b。本轮保持该仓库只读，没有执行其 Windows 程序、测试或自检。

| 原版模块 | Swift 实现 | 行为 |
|---|---|---|
| app/movement.py、pet.py | Resources.swift、Pet.swift | 时间窗、射线移动、朝向、上下飞行、闲置调度、吸边和工作动作 |
| app/video_frames.py | Resources.swift | FFmpeg 显式 libvpx-vp9，输出 RGBA 保留透明度 |
| app/chat_backend.py、chat_ui.py | Codex.swift、ChatController.swift、ChatUI.swift、History.swift | JSON 行协议、角色指令、历史、公开摘要、任务终态、停止、审批及补充问题 |
| app/desktop_task_sync.py | DesktopSync.swift | 只读公开字段投影、逻辑/实际 ID、失败提醒、通知去重、终态 |
| app/platform_support.py、mac_autostart.py | Pet.swift、Autostart.swift、main.swift | Mac 原生生命周期、全屏、单实例和可选跟随启动 |

协议以本机已有 CLI schema 与 [官方 App Server 文档](https://learn.chatgpt.com/docs/app-server) 为实现依据。未发送模型请求，不复制登录凭证。

## 明确的 Mac 选择

- Swift + AppKit 从零实现；不是将旧 Python 界面包一层 Swift。不存在 Python/PySide6 运行时。
- 原生 NSPanel/NSWindow、菜单栏、材质、文本和审批窗口。视图坐标与窗口坐标在边界转换，Retina 不重复放大布局。
- 第一阶段保留原 WebM 和随包 FFmpeg，不转码素材。后台按需解码并缓存，先显示首帧；非固定帧缓存预算为 192 MiB，总内存还包括当前动画和在途帧。
- 移动参考作者算法，保持整条路径方向；休闲在动作开始时按偏好设下一次期限（默认 15 秒），在片段边界切换。移动结束有 10 秒冷却。
- 吸边拖出后直接待机是用户指定差异。任务开场先 work01，再进入常规工作；成功时庆祝，失败/中断不庆祝。
- 多任务以活动集合协调，不照搬单一 task_active 布尔值。
- 历史使用新目录与显式 schemaVersion，不直接迁移旧工程历史。公开外部记录只能转成草稿，不能冒称完整分叉。
- 不复制作者每 2 秒写诊断文件的流程。不运行 SHA-256、截图或自动视觉检查。

## 资源来源及分发边界

动画：现有 `bailong-desktop-pet-mac/local-assets/windows-v0.5.1/outputs/白龙桌宠素材`，来自作者 v0.5.1 发布素材。图标沿用该工程按默认待机首帧生成的 ICNS；声音及来源说明取作者 app/sounds。

FFmpeg：imageio-ffmpeg 0.6.0 分发的 ffmpeg-macos-aarch64-v7.1 与 ffmpeg-macos-x86_64-v7.1（[PyPI 0.6.0](https://pypi.org/project/imageio-ffmpeg/0.6.0/)）。这里只复制二进制，无 Python 运行依赖。资源、二进制和 .app 均在 .gitignore 中。

作者仓库当前未指定开源许可证，动画也没有额外再分发授权。本工程独立维护，不新增或宣称对原素材的许可证。上游及素材授权尚未确认，相关许可材料仍待整理。

## 0.2.0 架构与验证范围

支持分开构建 arm64 与 x86_64 应用，最低目标 macOS 14。每包只携带对应架构解码器；关于页面按编译目标显示架构。Intel 交叉编译及静态架构检查不等于 Intel 真机运行验收。两包仅本地 ad-hoc 签名，没有公证或 GitHub Release。素材与二进制仍不进入 Git。

当前 x86_64 二进制的构建参数包含 `--enable-gpl --enable-version3 --enable-nonfree`，二进制内 libav* 许可字符串为 `nonfree and unredistributable`。Intel 关于页单独说明该事实，不沿用 arm64 的 GPL-2.0-or-later 文案。Intel 包仅本地使用，不上传源码仓库或 Release；未来公开分发需先替换该解码器并核对其依赖许可。

## 0.2.1 私有开发预发布

用户授权取消 Tests 追踪、版本升级、双架构构建、本地提交及远端推送，并将 ZIP 上传到现有私有仓库的 Release。该操作不变更仓库可见性，也不表示原作素材或 Intel 解码器获得公开分发授权。

本版包括产品名称范围修复、文本选择范围调整和 README 补充说明。两份应用均采用本地 ad-hoc 签名，没有 Apple 公证；Intel 未经实机测试。当前 Intel FFmpeg 仍包含 --enable-nonfree，关于页保留实际许可状态，不作为可公开转发的软件包。

许可证暂为本地待审方案，未添加覆盖整个项目的 MIT 声明。正式公开发行仍需落实上游授权及可分发解码器和相关许可材料。

### 0.2.1 发布范围调整

用户随后决定暂时只提供 Apple Silicon 版：从现有 Release 移除 Intel ZIP，并同步 README 与发布说明。Intel 源码、交叉编译入口和本地应用／ZIP 保留，不改变其尚未通过实机测试及解码器限制的状态。当前可下载应用仅为 Apple Silicon（arm64）。
