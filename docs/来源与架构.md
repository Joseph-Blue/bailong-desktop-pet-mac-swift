## 设置与历史界面

设置为贯穿侧栏与表单两栏；历史为贯穿会话侧栏与右侧阅读／输入两栏。使用 NSSplitViewController、NSSplitViewItem、NSToolbar 和跟随分栏的 NSTrackingSeparatorToolbarItem；侧栏可收起及调整宽度，内容从 safe area 下方开始。移除内嵌圆角侧栏、阅读区外框和自绘宽分隔带，保留输入框的边界。设置同类选项采用区外标题、浅底圆角分组及组内分隔线；分组承载语义，不包裹整个内容区。材质集中在原生侧栏与窗口工具栏。

设置表单最大 660pt，分类标题进入工具栏，恢复本页／全部操作固定在侧栏左下角；历史输入区仅占会话列，高度按文本在 76～160pt 范围调整。侧栏显示来源图标与单行截断标题，选中态区分活动／非活动窗口；路径正文仅显示文件夹名，完整路径保留在悬停提示中。原生图标按钮保留命令名称，可访问性标签区分本地与同步记录。

设计参考用户提供的 [macos-golden-gate-design](https://github.com/gambadio/macos-golden-gate-design) 及截图；API 依据 Apple 的 [NSSplitViewController](https://developer.apple.com/documentation/appkit/nssplitviewcontroller)、[NSTrackingSeparatorToolbarItem](https://developer.apple.com/documentation/appkit/nstrackingseparatortoolbaritem) 与本机 macOS 27 SDK。保持 macOS 14 最低构建目标，分栏不引入 macOS 27 专属调用；气泡玻璃以 macOS 26 可用性分支隔离。未读取 Figma 节点，未进行视觉、深浅色或无障碍运行验收。

## 动画与性能

当前 catalog 共 35 段 MOV，保留原动作清单的时长、缩放、偏移和位移参数。待机、第二待机、拖拽、落地采用去杂色及局部描边平滑后的素材：前三段各 96 帧／24 fps／4 秒，落地 48 帧／24 fps／2 秒，720×720。清理副本与原始 PNG 均保留。

默认清晰 512×512、24 帧后续缓冲、满帧播放。画质另有 384×384、256×256；缓冲可设整数 6～240，输入非法值在结束编辑时恢复 24；素材 FPS 上限可选“满帧 (≥ 24 FPS)”／20／15。满帧按素材 nominalFrameRate 与播放速度调度，当前 33 段为 24 fps、2 段为 30 fps，不插帧。FPS 上限与播放速度独立，时间轴和动作时长不改变。

流式读取在串行后台队列进行，首帧完成后开始播放，按视频 PTS 消费，缓冲满暂停读取。保留首帧、当前帧及一个在途帧；容量不跨动作预读。帧图像与 Alpha 命中同步缩放，首帧边界映射到 512 逻辑画布，菜单栏裁剪映射回实际像素。generation 屏蔽过期任务，循环回绕的 epoch 丢弃旧循环结果，退出等待当前解码结束。

“整段动画预加载”默认关闭；开启后完整读取当前动作再播放，同动作循环复用，切换动作重新载入，不预热整个素材库。启用后缓冲整行置灰，关闭恢复保存值。说明固定为“不推荐，会显著增加运行内存 (RAM) 占用。”设置顺序为画质、帧率上限、缓冲帧数、整段预加载。

默认画质下 24 帧图像及 Alpha 平面约 30 MiB，这只是像素估算，不是进程总运行内存 (RAM)。用户曾反馈 dev.7 约 280～300 MB，该值属于旧版 256×256 整段解码实测，不沿用为当前版本结果。

## 性能统计口径与窗口

统计默认关闭，只在窗口启用时采集。独立 NSWindow 默认位于主屏左上角，显示 Dock 图标，可最小化并从 Dock／菜单召回。左下角 pin 开关控制 floating／normal，默认置顶并记忆；右侧关闭与拷贝按钮同排。红灯和关闭按钮销毁窗口并停止采样，绿灯禁用。设置中开关窗口保留设置 key window；不设置自定义悬停说明，高度按内容收紧。

- FPS：SpriteView.draw 完成后的不同画面数，重复绘制不重复计入；每秒采样，保留 60 点，HI／LO 为本次开启极值，包含暂停和隐藏。不是显示器扫描刷新率。
- CPU：getrusage 进程累计 CPU 时间差分；总体占比除以逻辑核心数，单核基准以一个核心满载为 100%，允许超过 100%。不是最忙核心读数，也不对大小核算力加权。
- GPU：PROC_PIDCOALITIONINFO 与 coalition_info_resource_usage 的 gpu_time 差分，显示应用资源组口径，包括同组子进程；不等同于整机 GPU 饱和度。失败显示错误，不伪报零。
- 运行内存 (RAM)：TASK_VM_INFO.phys_footprint；压缩量单独读取 compressed。驻留帧按图像及 Alpha 字节估算，重复引用去重；系统图形／解码资源不包含在帧估算中。
- Swap：系统交换空间来自 vm.swapusage；本进程累计换入来自 ledger_swapins，并按返回结构长度判断字段是否存在。正数表明曾换入，零不排除已换出但未读回；不提供无法确定的本进程当前磁盘换出量。字节口径依据 [Apple XNU 实现](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/vm/vm_compressor.c)。
- 当前无应用自建的动画磁盘缓存，不把素材文件或会话文件算作缓存。
- 分开显示 Codex／ChatGPT 桌面进程及只读同步状态、桌宠自身 CLI app-server 状态／PID／路径；连接不等同于登录或配额有效。

## 临时气泡与历史边界

“我还在留意进展…”与“让我看看额度…”的标题由 Bubble 显示层添加十帧盲文字符和一个空格，每 100ms 更新，只有盲文字符使用当前强调色，文字保持普通标签颜色。相同气泡正文更新不重建动画计时器；标题替换或隐藏时停止，关闭释放计时器。传入文本和 History 数据不加盲文字符。任务完成、失败及额度结果沿用各自展示，不把加载动画持久化。

## 更新与网络

设置独立“更新”页，应用菜单、桌宠菜单提供手动检查。默认启动检查一次，开关持久保存；发现新版时展示更新窗口但不抢 key window，失败只记录在设置页。上次完成检查的本机时间和结果存入 UserDefaults，重启后可查看；取消的检查不覆盖上次完成时间。手动失败在窗口内显示原因，支持重试。只有自动发现新版的弹窗在“重新检查”右侧显示“😡 不许打扰我，禁用自动更新检查”；点击后关闭弹窗、持久禁用启动检查并同步设置页开关，手动打开同一窗口会隐藏此按钮。关闭窗口／退出应用取消请求，generation 丢弃旧回调，手动检查复用正在执行的启动请求。

从公开仓库的 `/repos/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/latest` 读取正式发布；不使用登录凭证。按 [GitHub 最新发布 API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release) 处理状态码、限流、JSON 错误；超时为请求 20 秒、资源 30 秒。按 [SemVer](https://semver.org/lang/zh-CN/) 比较核心版本及预发布标识，忽略构建元数据，兼容 `白龙娘桌宠v0.2.1`、`v0.2.1` 和普通版本标签。本地领先不会提示降级。更新说明采用现有 Markdown 文本渲染，下载按钮只打开本仓库发布页；没有自动下载、安装、退出或替换应用的代码。

错误展示拆成 UpdateFailure 的标题、说明与技术详情；仅 NSURLErrorNotConnectedToInternet 显示系统离线，GitHub 连接失败／超时不等同于用户断网。区分 DNS、接收中断、安全连接、代理认证、403 拒绝与明确限流、404、5xx、空响应、JSON、正式版本标签和本地版本错误；保留错误域／代码或 HTTP 状态及相关响应头，不展示响应正文。限流有恢复时间时显示时间，未提供时提示稍后重试。

检查 8 秒仍未完成时，现有手动窗口显示“连接 GitHub 较慢”，保持加载并提供取消检查；不创建后台慢速弹窗。完成、取消及退出清理慢速计时器，旧 generation 不更新界面。失败窗口只显示当前版本，短标题配一句说明，技术详情默认折叠，可展开和拷贝；底栏依次为关闭、查看发布页、强调色重试。自动检查失败仅持久记录“检查未完成 · 原因”及时间，不弹窗。未联网不能判断为代理故障，不要求用户开启 TUN。

每次检查新建原生 URLSession，保留系统代理默认值，适用于系统 HTTP／HTTPS／PAC 配置及 TUN 系统路由，不写入代理端口、不修改系统代理。Apple 说明：[默认代理设置使用系统配置](https://developer.apple.com/documentation/foundation/urlsessionconfiguration/proxyconfigurations)。此能力只描述应用更新请求，不代表给 Codex CLI 注入代理。

## 气泡材质与设置交互

普通消息、进展、额度、失败、任务回复和临时输入窗共用 BubbleBackgroundView；正文固定在根视图的 body 子视图内，玻璃位于独立底层，普通背景覆盖层位于两者之间；切换材质不重挂正文。支持系统默认玻璃并跟随系统，普通模式保留原实色背景；低于 macOS 26 的运行分支不初始化玻璃 API，材质选择禁用并显示普通材质。系统降低透明度时即时回到实色，保存选择保留。

跟随系统使用 regular 样式，无自定义衬底；手动模式采用 clear 与可调衬底，不改变正文或窗口 alpha。不透明度保存为 0～1，默认 0.5；其含义是应用背景的遮蔽程度，不是 Apple 私有的系统玻璃滑块参数。原生 API 依据 [NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) 及 SDK 声明。

设置预览为单独非激活 Bubble，不访问模型或真实消息；拖动时保持显示，松手三秒收起，切页／关闭设置立即隐藏。连续材质偏好通知只触发背景更新，跳过 Pet 的任务同步和运动调度。偏好支持导入／导出和本页／全部恢复。

玻璃滑块图标来自系统符号库 capsule.on.rectangle.liquid.glass 与对应 fill，目录标记为 2026 新增；在 macOS 27 使用 NSImageView.dataWithPDF 导出资源，并在 macOS 26 从包内读取。没有窗口截图或视觉检查。符号 PDF 保留本地，不进 Git；导出工具追踪，构建将 glass-symbols 加入资源。

强调色默认“跟随系统”，色点首位；其余颜色有蓝、紫、粉、红、橙、黄、绿、石墨及自定义。色点为原生 NSButton，使用系统色、选中双环、名称及可访问性标签；系统颜色变化通知刷新当前强调色。旧的手动选择不迁移覆盖。

现有 7 处 NSAlert 已核对主按钮：错误知晓、任务同步状态、技术详情拷贝、跟随启动配置、审批、补充输入、全部重置。主操作颜色和键盘默认分别配置；审批仍回车拒绝。恢复全部标为 destructive、红色、无默认回车，局部事件监测同时屏蔽 Return 和小键盘 Enter，完成后移除；Esc 取消。系统保存和文件夹选择对话框沿用系统强调色，不修改其私有控件。

应用在 NSApplication 初始化前设置当前应用域 NSInitialToolTipDelay=200，保留原生 tooltip 实现。该偏好键不是公开 AppKit 属性；配置为 200 毫秒，本轮未测量实际显示延迟。全部改动仅编译及静态核对，气泡材质、颜色、分组、预览、键盘及悬停表现待用户运行 review。

0.4.0-dev.11 修正危险按钮：侧栏由 SettingsFooterButton 绘制淡红底及动态 systemRed 文字，浅色常态底色 alpha 0.16、深色 0.22，另区分按下和禁用；保留 NSButton 的键盘、焦点和辅助功能。NSAlert 只使用 hasDestructiveAction，不覆盖系统危险按钮底色。回车拦截不变，未进行视觉或运行验收。

### 侧栏与开关动画修正（dev.6）

设置及历史仍使用 NSTableView；style 为 plain，selectionHighlightStyle 为 none。AccentHistoryRow 在 drawBackground 绘制选中背景，避免 sourceList 的系统选中层绕过 drawSelection。左右按视口各收进 10pt，圆角 7pt，上下 2pt；选中和强调状态改变时同步文字与图标，失焦使用系统灰色。

NativeAccentTint 在关闭状态也保持挂载，原生动画全程经过颜色映射；仅切回“跟随系统”时移除滤镜。不再按 state 变化安装／卸载滤镜。此轮不执行窗口或动画视觉验收。

### 气泡动态效果（dev.7）

外观／消息窗口新增 bubbleMotion 开关，默认 true，纳入恢复本页、恢复全部与偏好导入导出。BubbleMotion 统一消息气泡与临时输入窗的逻辑显示状态、实时目标位置、160ms 淡入+4pt ease-out 位移、120ms 淡出和 140ms 高度过渡。仅短过渡期间使用主线程 common-mode Timer；结束或销毁时停止，无持续动画轮询。快速重开从当前透明度接续，没有延迟 orderOut 回调。跟随移动直接改目标位置，尺寸与透明度不重新排队；正文更新不重播出现动画。

BubbleBackgroundView 的正文永久固定在根视图，玻璃位于底层、普通背景覆盖层位于中间。切换时仅过渡普通覆盖层的透明度，玻璃在普通背景完全覆盖后才隐藏；160ms 结束后停计时器。滑块调玻璃不透明度仍即时更新，不重置过渡。不截取窗口快照，不缩放文字或重挂输入框。

关闭动态效果立即落到当前目标状态；减少动态效果时仅保留短淡入淡出，取消位移、高度与材质动画。不改变独立 typingEffect 和盲文加载提示。编译不代表动画真机验收，禁止自行截图或启动视觉测试。

### 设置操作区对齐（dev.8）

alignedRow 统一固定操作区 trailing；compactControl 递归收紧组合控件，NSStackView 使用 fill、零 edgeInsets，并按 fittingSize 固定无显式宽度的操作组。避免外框右对齐而内部 gravity 仍留白。已有固定宽度沿用，普通数值／缓冲滑块组均为 272pt，玻璃双图标滑块组为 244pt；只读值在自身框内右对齐。标题和说明左对齐，色点名称居中，单选组内部左对齐；不把所有文字一概右对齐。分类单元格清除 tooltip，侧栏工具栏按钮显式保留 tooltip，辅助功能名称保留。

### 素材播放与几何动画解耦（dev.9）

configureAnimationTimer 仅按 animationFPS 驱动素材选帧及动作调度。吸边收起／展开和自主移动在 updateGeometry 内由 NSView.displayLink 驱动；macOS 14 起可用，回调同步视图所在屏幕，跨屏无需硬编码刷新率。弱 target 避免控制器循环引用，静止和隐藏时暂停，close/deinit 时 invalidate。

保留作者 300ms 吸边缓动及移动素材的 moveStartMs/moveStopMs 时间轴。显示刷新复用当前 CGImage，不调用 selectFrame；结束时保留动作切换，并将自主移动落到终点。拖拽仍由鼠标事件立即定位。素材帧率上限独立于刷新率；统计中的 FPS 由不同图像计数，draws 允许同一图像多次绘制。

本地 SDK NSView.h 的 NSDisplayLink 分类明确 API_AVAILABLE(macos(14.0)) 与视图屏幕同步行为。未运行窗口、截图或真机刷新率验收。

### 窗口、提示与任务时长（dev.10）

设置 show 设置 regular activation policy、注册窗口菜单并还原最小化状态；Dock 加设置入口，reopen 优先还原最小化窗口。关闭统计不强制切回 accessory。AppDelegate 区分显式完整退出和界面关闭：⌘Q 走 closeInterface，Dock terminate 在非明确退出时取消终止；sheet／模态窗口按取消处理，保留审批默认拒绝及补充输入取消的原行为。完整退出继续回收任务进程；系统 willPowerOff、SIGTERM/SIGINT 保留正常退出，不以此阻止系统结束会话。

WindowFade 只管桌宠 alpha，不干预位置；首帧准备后才开始出生淡入，全屏避让与手动隐藏共用 160ms／120ms，关闭 bubbleMotion 立即完成过渡。设置独立注释使用 note 工厂（11pt、secondaryLabelColor），group 遇注释不插前置分隔线；行内 detail 同样保持次级灰色。自定义色点符号为 paintpalette，关闭气泡用辅助功能名代替 tooltip。

Bubble 接收任务开始时间及任务 key，右上角 stopwatch 与单宽数字显示 MM:SS／H:MM:SS，最小 00:00。内置任务用 Turn.date（提交时，含启动等待）；外部任务使用本地 thread_turns.started_at，经现有每秒同步发现，非远端零延迟查询。气泡计时每秒本地计算，更新同一任务不重启计时器；匹配任务结束、气泡隐藏或销毁停止刷新，不写入历史。开始时间缺失的外部任务不伪造时长。

文字流水仅用于 animated heading 的正文：1.2 秒亮带扫过、2.8 秒停顿，使用渐变文字透明度，盲文和空格排除；盲文仍约 10 次／秒切换并跟随强调色。文字效果遵守 bubbleMotion 和 Reduce Motion，不重置任务时长。

素材帧率选项精简为“满帧 (≥ 24 FPS)”／20／15。当前资源通过 AVFoundation 元数据读取确认：33 段 24 fps，move03left／move03right 两段 30 fps。Animation 保留 nominalFrameRate；满帧调度为源帧率乘播放速度，20／15 为上限。用户偏好和旧导入文件的 24／30 迁移到 full。几何 display link 与素材调度继续独立。

任务计时排版（dev.12）：关闭按钮、标题首行、计时组同一行；秒表紧贴实际文字宽度，间距 3pt（随气泡比例缩放），计时整体右对齐。标题按剩余宽度换行，不截断或缩字；跨小时重排，正文与计时不重叠。任务结束后保留最终用时并停止计时器，completed 使用 systemGreen，failed／interrupted／cancelled 使用 systemRed。内置任务按完成事件到达时冻结；外部任务优先使用 thread_turns.completed_at，未提供时用观察到结束的时间。

文字流水方向：浅色模式保留深色底字，扫过时降低文字不透明度形成浅色带；深色模式为灰字被亮带扫过。禁止浅底界面把浅字作为常态、深字作为扫过效果。

## 新鲜额度查询与重置卡（dev.12）

dev.13 结果正文修正：DesktopSync 使用 TaskOutcome 分别生成完成／失败／中断标题和正文。禁止以 value.title 回填空回复，该字段是会话标题，常来自用户首条输入。错误 JSON 只提取 message；没有错误说明或最终回复时直接显示对应状态说明。历史会话标题照常保存，不删改用户记录。

QuotaQuery 每次新建，不跨查询保存额度。连接仍复用，但先发 account/rateLimits/read，再并行 account/read(refreshToken:false)；额度响应直接展示，账号晚到只补同次套餐信息，不重新播放出现动画或重置气泡倒计时。serial 与 quotaActive 继续拦截关闭气泡、换任务后的旧回调。失败显示错误，不用旧成功结果回退。

保留默认的完整额度读取，不设置 excludeResetCreditDetails=true；本机 Codex 导出的协议确认默认读取包含额外的重置卡明细查询。QuotaResetCards 使用 rateLimitResetCredits.availableCount 显示可用张数，按 expiresAt 分组、由早到晚显示到期时间。显式 null 表示不限期，字段缺失或明细未提供显示未提供。明细列表允许被服务截断，不以列表长度替代总数。只展示，不调用 consume，不消耗卡片。协议：[额度接口](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)。

用户允许本轮测试：真实只读请求测时、协议数据回归及临时 AppKit 窗口几何／计时断言；未发起模型任务，没有截图或视觉审美验收。具体测时与运行记录保存在本地实施记录。
