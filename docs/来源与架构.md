<a id="current-bubble"></a>
### 气泡与显示

- `BubbleBodyScrollView` 管理自然高度、视口和纵向阅读位置，`BubbleBodyLayout` 统一正文宽度；左右边距对称，默认 21pt 随比例缩放，小比例容纳系统轨道及 2pt 间距。轨道占用右边距，`lineFragmentPadding=0`；显隐不改变换行宽度，过渡不把 contentView 宽度回写正文。多行容器关闭横向弹性并固定横坐标，单行系统编辑器保留原生滚动。
- 应用自建纵向滚动区域显式允许 AppKit 原生边缘回弹：正文、编辑器、设置、列表、搜索、模型弹窗和诊断详情共用该行为。气泡同尺寸视口重复排版不重新钳制阅读位置；显式回顶部、恢复位置和真实尺寸变化仍按内容范围限幅。短进展等明确不滚动的正文不启用回弹，不更改系统滚动条样式或模拟滚动事件。
- `MessageTextView` 使用同一 TextKit 容器测量和显示，保留未变化前缀，仅更新变化尾部；不加高度估算、持续锁顶或追尾。普通气泡打开、切卡及正文变化从顶部显示；配色刷新保留阅读位置。只有内容溢出才显示原生滚动条；工具短进展按真实视口、字素边界截断并加 `...`，不滚动，hover 使用同一份有界摘要。
- `BubbleCardStore` 负责身份、保留上限、优先级与选卡，`BubbleCountdown` 管理停留时间；卡片保留原问卷与草稿。优先级为待处理请求＞任务消息＞概览／随机台词，用户翻阅或填写／提交问卷时不自动切卡，同条流式消息原地更新。已处理请求移除；额度、独立预览和普通动画对白不进任务卡片。
- 仅鼠标绑定 `random` 显示并复用一张 `taskOverview` 卡；每次召回更新工作中台词与列表，移到记录末尾。`randomAnimation`、菜单随机动画及指定预览只播放动作与一句台词。任务列表每会话仅取最新真实轮次，不能从旧历史推断执行中；助手卡片按真实消息 ID 区分，不按整轮、空行或 interaction 类型合并。
- 卡片数 5～100（默认 20），近期结束任务 1～20（默认 5）；保留当前阅读和待处理卡片。单卡仍显示 1 / 1，首尾箭头置灰。两列底栏为转到 Codex／查看记录详情、翻页区／快捷回复；按钮等宽等高，按当前比例排版。移入暂停、移出续计时，翻页重计时，后台到达不取消倒计时；审批、问卷、错误手动处理。
- 气泡及输入窗跟随桌宠拖动，动作切换／吸边不主动隐藏。`BubblePlacement` 按角色可见区域、屏幕与输入窗四向避让；刘海收纳大气泡依次优先左、右、下、上。角色下方固定上边缘向下展开，上方固定下边缘向上展开；上下方高度变化重新锚定角色，侧向仅在选边不变且安全时保留原点，不能按刘海状态统一伸展方向。单击互动与输入窗顶部优先，新消息重置选边，重排保留草稿。
- 仅刘海收纳／展开的 0.3 秒过渡中，主气泡与短进展以展开、收纳两端的可见轮廓插值作为锚点，复用原 dockProgress；不逐帧跟随 180° 旋转外接矩形的伸缩。两端与实际轮廓相接，窗口位移仍直接跟随；普通拖动、左右吸边、鼠标命中、输入窗及 BubblePlacement 选边规则不改，无新增计时器。
- `InlineStatusLayout` 统一文字基线与图标 capHeight 中心；盲文按完整 ⣿ 的 NSTextFieldCell 尺寸计入内边距，所有帧固定布局。2 秒短气泡为盲文＋固定操作图标＋文字，仅文字应用标题效果。主气泡进展独占新增高度，只滚文字，新内容先停留 0.5 秒，同文更新保留相位；任务结束收起。进展不生成额外活动卡片。
- 进展图标由 `TaskActivitySymbolView` 共用原生 NSImageView：主进展／概览在默认比例下 15pt，短进展及待处理标题至少 16pt，统一 semibold；跟随气泡比例及消息字号，操作图标使用与高度相同的固定宽度槽位，宽符号等比缩放，不再随符号宽高比扩张文字占位。主气泡和概览的操作图标跟随相邻进展文字颜色，普通进展为次级灰，短进展标题图标沿用正文色，状态使用语义色；外观切换保留配色角色。固定图标和结果标记均不参与单行跑马灯。失败／拒绝／取消或中断以独立结果标记紧邻操作图标，布局计入标记宽度；隐藏及销毁释放显示引用、停止呼吸效果。等待用户时隐藏执行盲文，仍保留真实任务计时。
- 执行计时用真实任务开始时间，每秒更新，stopwatch 与时间整体右对齐，格式 MM:SS／H:MM:SS、最小 00:00；完成冻结，外部优先 completed_at，缺失才取观察到结束时刻。完成用时绿，失败／取消／中断红；概览完成绿对钩、失败黄感叹号、取消／中断红叉，缺失时间不伪造。
- `ProgressTextEffects` 共用标题 1.2 秒扫光／2.8 秒停顿；`ProgressMarqueeView` 超宽才以 28pt/s 循环，衔接处显示两侧留空的“·”，同文刷新保留相位。分隔符只参与滚动显示，静态文字及辅助功能原文不添加。盲文仅显示层生成，隐藏、标题替换、销毁及结束停止；动态效果关闭或系统减少动态效果时静态。正文打字机停用，旧 typingEffect／countAfterReveal 只作兼容。Core Text 颜色按视图 effectiveAppearance 解析，外观变化重绘而不重置相位。
- 动态效果默认开启：出现 160ms 淡入＋4pt 位移，关闭 120ms，高度 140ms，材质背景 160ms；正文不缩放，桌宠移动直接跟随。快速重开取消旧关闭，关闭效果或减少动态效果立即结束相应过渡。退出淡出与停止、保存、回收并行，全部完成才答复系统退出，退出中不接收旧动画回调。
- macOS 26 起默认液态玻璃，旧系统固定普通材质且选择置灰，偏好持久化；降低透明度用实色背景，不透明度仅调背景。当前玻璃试验使用无焦点、忽略鼠标的独立背景窗，正文仍可选择编辑，位置、尺寸、层级、显隐及淡入淡出同步；普通材质单窗口。预览独立，不抢焦点或覆盖任务、不写历史；玻璃焦点效果继续待用户验收。

<a id="current-windows"></a>
### 输入与窗口

- 临时聊天用 `nonactivatingPanel`；`ContentCursorPanel` 将 ⌘X／⌘C／⌘V／⌘A 发给本窗第一响应文本视图并做原生有效性校验，不依赖前台应用菜单或主动激活应用。可选文本右键仅剪切／拷贝／粘贴／全选，模板编辑器另保留变量插入；链接手形按实际 TextKit 字形命中，鼠标处理不得覆盖。手形问题仍按 TODO 跟踪，不能以源码接入宣告已修复。
- 临时聊天、历史回复、问卷共用 `MessageEditor`／`MessageInputBox`。NSBox 与原生焦点层同级、共同父视图后激活四边约束；不把焦点层塞进 NSBox 内容区或依赖零尺寸 autoresizing。发送方案由 `SendShortcut` 共用，保留主回车／小键盘 Enter、中文组字及防重复发送；提示统一符号与真实 Tab 制表位，不增加符号首次介绍或备选说明。临时／历史提示在发送 hover，问卷保留底部提示。
- 临时输入用原生分段导航，目标选择同行右对齐，输入按草稿增高并封顶；短普通状态放得下才与模型同行，错误／多行／超宽状态独占整行、96pt 封顶纵向滚动且全文可复制。模型弹窗按可见说明、字号、宽度和屏幕测量，隐藏内容不占位，展开固定锚点宽度，超高可滚动，关闭释放；推理标签按宽度换行，思考滑块松开提交并保留键盘操作。
- `ChatNavigation` 管目标，`ChatDraftCache` 按入口／会话存草稿；历史浏览与临时发送不能共用选择变量。主按钮统一发送，停止独立；异步回执不清除后来目标的草稿。外部模型字段由 `DesktopReply.Settings` 提供，只读，不冒充桌宠模型；首次设置读取成功后才开放发送，失败保留草稿与真实原因。
- `InterfaceWindows` 只登记未关闭普通窗口；最小化／隐藏保留 Dock，最后关闭收回，召回不重建已关闭窗口。⌘Q／Dock 退出只关闭界面或取消对话框，完整退出在桌宠／应用菜单保留，系统关机／信号正常清理。设置／历史绿灯填满可用屏幕再恢复，不进独立全屏空间；设置首次填屏、已有记录恢复位置尺寸，标准 1040×900pt、正文最多 780pt；历史初始 1100×850pt。
- 后台刷新、开关联动、关闭回调不激活其他窗口。再次打开 App 显式召回桌宠并展开吸边，保留任务，暂时让全屏自动隐藏让位；鼠标按下阻止默认窗口排序。输入窗先定位、主气泡避让、短进展让位；空间不足保证输入在上且不丢请求／草稿。
- 文件浏览／保存用 `PanelPresentation` 原生独立模态，在发起屏幕首次布局后居中一次，可拖动；`CenteredColorWell` 只在打开时定位。`HoverHelp` 延迟 200ms、淡出 80ms，离开／点击／滚动／关闭取消；一般说明完整排版，工具保持有界摘要、最近回复最多 200 字。气泡关闭、翻页及性能窗口不新增 hover，保留辅助功能名称。

<a id="current-tasks"></a>
### 会话与任务

- 内置 `ChatController` 拥有连接、任务生命周期与历史协调，`TaskMessageAccumulator` 聚合公开消息；同连接 start／resume 成功后复用身份，thread/closed 或连接关闭清理，不反复 resume、抢 writer 或自动重发。每轮发送所选 model／effort。
- 外部 `DesktopConversationSession` 管设置、回复／插话及待确认状态，观察由 `DesktopHistoryReader`／`DesktopSync` 提供。用户明确提交后走既有桌面 IPC start-turn v2／steer-turn v1，排队不开放；发送前核对最新轮次，沿用原会话模型／档位／权限、不加桌宠人格。未加载会话不自动激活或用内置连接接管；超时／不完整回执保留草稿与待确认，不自动重发。
- 审批默认拒绝。外部批准前重新核对 owner／请求／轮次／操作内容，详情缺失不能允许，提交后确认移除；回执只更新原表单。气泡拒绝／允许无默认回车或快捷键，顺序设置仅作用于气泡；敏感问题只跳 Codex，不展示问题、选项、输入或保存答案，历史仅保留角色标记。非敏感问题逐题处理，上一题／跳过／下一题保草稿，末题提交非空答案，跳过不造答复；按问题 ID 判断已回答，不自动关闭。
- `TaskActivity`／`DesktopRuntimeProjection` 只使用公开 reasoning.summary、commandActions／tool／namespace／server／changes 等结构化字段；原始推理、工具输出与用户输入不进进展。运行工具优先于旧摘要，空摘要不擦除同阶段标题，不显示泛化“思考摘要”占位。普通命令保留首行子命令、参数和对象，多行标省略，不猜脚本意图；最多 3 条、每条 120 字，余项计数，hover 同摘要。思考图标 atom，操作图标固定、不跟文字滚动。
- 等待批准／回答单独归为 attention，分别使用 hand.raised／questionmark.bubble；内外会话及待处理气泡共用。工具失败、拒绝、取消／中断保留操作图标，分别附 exclamationmark.circle.fill／hand.raised.slash.fill／xmark.circle.fill；只有 completed 使用“已读取／已运行”等完成文案，动态工具 completed 且 success=false 按调用失败显示，不据此结束整轮。
- 内置计划通知、公开 plan 项及 item/plan/delta 使用 list.bullet.clipboard，最终计划替换流式草稿；外部数据库和实时投影读取 plan 项。进展投影中的计划正文最多 8192 字，沿用三条／每条 120 字工具摘要；不因此放开助手、用户或原始推理正文。本机协议 collabAgentToolCall（亦识别官方文档中的 collabToolCall）的协作使用 figure.and.child.holdinghands，wait 使用 figure.child.and.lock，仅显示工具操作，不读取子代理提示词或答复。enteredReviewMode／exitedReviewMode 使用 doc.text.magnifyingglass，模式标记不作为持续运行工具压住后续进展。
- 网页 action 按 search／openPage／findInPage 区分搜索、打开网页、页内查找，分别使用 globe／network／doc.text.magnifyingglass；投影只保留公开类型、查询、URL 与查找词。MCP／动态工具按明确 namespace／server＋tool 身份映射：命令、文件编辑、查看／生成图片复用原分类；文档 doc.richtext、表格 tablecells、幻灯片 rectangle.on.rectangle、邮件 envelope、日历 calendar、代码解释器 curlybraces。未知工具及 functions.exec 编排容器保留 wrench.and.screwdriver，不根据参数或脚本猜测内部操作。
- 进展按真实会话＋轮次＋开始时间匹配；内置用 activityKey，不取全局最新任务。实时只保留目标轮次公开 items，其余保留身份与槽位以维持补丁索引；目标变化重取快照。审批详情不裁剪。既有进展约 0.2 秒、数据库 1 秒、标题 5 秒的间隔不作为端到端延迟实测，也不随显示功能提高轮询。
- 重连读取内置 error.willRetry／外部本轮公开 error，次数取源消息，不硬编码总数。wifi.exclamationmark 橙色呼吸，真实模型进展确认恢复后 wifi 绿色保留约 2 秒；最终 failed 才显示 wifi.slash 红色“重新连接失败，Codex 已停止重试。”及网络／节点检查说明。更新本轮原卡或复用一张连接卡，保留阅读／问卷优先级。`CodexErrorMessage` 统一常见错误中文、保留技术原文，429 不一概当额度耗尽；本机协议断开与上游重连失败分开。
- 仅 completed 成功；无最终正文显示真实完成／失败／中断，不用会话标题或用户输入回填。用户输入由 `UserInputText`／`MarkdownText.renderUserInput` 共用，包装转换为提问与紧凑附件链接，不读取图片载荷或重复加占位。项目插话按真实 userMessage ID 合并，排除问卷回执、沿用原任务计时；人设会话不因此获得执行中发送能力。

<a id="current-history"></a>
### 历史与数据

- 设置域 `com.bailongpet.appkit.settings.v2`，首次只迁移已知设置、位置、内置模型并保留旧域；Bundle ID、数据目录及角色名不因产品改名迁移。历史 schema 1／2 JSON 首次事务迁移到 SQLite schema 3，保留 JSON；损坏、不支持、读取或迁移失败只读，不阻止桌宠／设置启动，不覆盖原库，提供导出和重读。
- 记录默认开启，关闭冻结快照，不录入或补录关闭期间变化；保存失败暂停自动写入，仅显式重试。正文按需读 history.sqlite，常驻仅元数据，LRU 最多 16 条／2 MiB、超限单条不缓存；冻结正文不可变共享，保存只插入变化正文和轻量索引。历史每页 20 轮，切页替换富文本，隐藏／最小化不扫正文，关闭释放正文、排版及搜索缓存，保留草稿与选择。
- 标题取 threads.name，未生成沿用 title 并按既有 5 秒补查；本地重命名保留，明确同步才恢复跟随。历史按真实最近消息／开始／结束时间排序，同时间稳定，流式正文真实变化才更新 lastMessageAt。删除通过事务移除正文并保存删除身份防回填；内置运行中先停止，外部只停止观察，不停止 Codex。

### 动画与吸边

- 透明 HEVC／AVFoundation 解码，当前缩放与颜色转换为 CPU／vImage 试验；显示由 SpriteView 的原生图层负责。FFmpeg 回归暂缓，尚未实现。切换只取消待完成加载，旧流不断，流式准备首帧和约 250 ms 的可播放余量后交接，按实际采样间隔与速度计算并受队列上限约束；短片读完可交接，整段预加载等全段完成。交接后补充至原队列上限。取消、配置变化和退出释放流，只准备当前请求、不预热全库；落地末帧等待，其他循环不变，按下桌宠不暂停选帧。
- 默认流式、较高 512×512、12 帧缓冲、满帧，保留已有值；缓冲 6～240，非法结束编辑恢复 12。画质原画 720／较高 512／中 384／低 256，以及可选自动档，以真实 Tab 对齐，保留 512 逻辑坐标及 Alpha 映射。自动按角色尺寸×动作绘制比例×窗口 backingScale 选择足够的最小档，最大 720；在新动作请求时取样，跨屏或缩放不重启动作，同段整段预加载复用须匹配实际尺寸。满帧依实际帧率×速度，选项“满帧”／20／15，完整诊断同步简写；旧 24／30 迁移 full，不固定 30Hz。整段预加载默认关，开启置灰缓冲与开头缓存、不清值。
- 流式低帧率档在颜色转换前，按源时间戳选取覆盖目标显示时刻的样本；源时间轴采样上限为显示 FPS 上限除以播放速度，不改动作时长。跳过的样本仍完成 HEVC 依赖解码，不生成缩放图像和 Alpha 命中遮罩。档位／速度变化更新后续供帧，已准备的队列按原时间戳消耗；不重启动作。满帧及整段预加载保留全部源帧，后者支持直接改帧率及变速。
- SpriteView 使用 AppKit 图层视图，图像子层的 CALayer.contents 直接引用当前 CGImage；普通桌面、左右吸边、刘海和全部动作共用，保持完整帧与原解码链路。子层尺寸沿用 drawRect，位置与线性矩阵组合等价于原 transform；根层只在刘海状态裁切，Alpha 命中仍按原逆变换。使用原生 Core Animation，不引入新的 SDK 档位或高于 macOS 14 的要求。
- 比较图像身份、绘制区域、视图范围、变换、刘海裁切与屏幕倍率，仅变化时提交图层状态；禁止隐式动画，素材选帧及几何 displayLink 仍各守原职责。系统阴影继续按状态变化失效；隐藏淡出完成后清空图层内容及状态引用，召回恢复当前帧，关闭时释放。显示层不持有动作缓存。周期气泡定位只跟随锚点、屏幕可用范围及吸边状态变化；正文、尺寸和输入窗更新仍明确调用原定位入口，鼠标命中持续检查。
- 性能页“动画效果改善”集中动态效果、动作平滑过渡、孤立杂点清理与轮廓阴影。`animationSmoothTransition` 与 `animationEdgeCleanup` 默认开启，已有明确保存值优先；沿用布尔设置导入导出、性能页恢复及静态搜索索引。动作过渡继续依赖动态效果开关与系统减少动态效果，设置说明只保留效果描述；自动画质生效时机保留原实现，设置页不再显示该说明。24 MiB 开头缓存默认开启，保持独立开关及预算。
- 动作平滑过渡只在有效新请求交接时比较当前帧与新首帧：按双方素材 renderScale／renderOffset 映射到同一坐标，64×64 取样 Alpha，以 min／max 总和计算加权重合度；达到 90% 且非同一动作、非收纳几何动画时，向 SpriteView 图像子层提交 180 ms CATransition.fade。原选帧继续推进，无逐帧 CPU 混图、额外解码或计时器；仅保留当前一次离场 CGImage 引用，结束回调核对过渡代次。完成、隐藏、关闭、快速替换、几何／屏幕倍率变化或停用动态效果时清理；命中与气泡锚点仍取当前动作。90% 为实验门槛，视觉与原生合成的图形内存成本待验收。
- 孤立杂点清理在 CPUFrameConverter 产出预乘 RGBA8 后、创建 CGImage 和 Alpha 命中遮罩前执行；仅删除八连通区域中全部 Alpha ≤ 16／255、且面积不超过 512 档 4 像素的小块。面积随目标尺寸平方缩放，256／384／512／720 档分别为 1／2／4／8 像素；连到主体、较大柔边或较高 Alpha 装饰时整块保留，未删除像素逐字节不变。每个候选最多访问面积上限加一个节点，不创建整帧连通标签缓存，不修改源文件或颜色缩放管线。设置变化清理开头缓存并按原重载路径保留当前帧、准备新段；流式与整段预加载共用，缓存键含清理状态，避免混用处理结果。此开关不代表阴影黑点已修复。
- Decoder 可选常用动作开头缓存，默认开启，已有明确保存的开关值优先；恢复性能页／全部默认值采用开启。整段预加载暂停缓存并保留开关值。只保留已成功交接的常用待机、拖动、落地、额度动作的前缀，最多 6 帧；LRU 按 RGBA 和 Alpha 遮罩的字节计量，运行内存（RAM）缓存上限 24 MiB。键包含素材路径、画质、帧率上限、限帧时的速度及杂点清理状态；变化配置、隐藏、关闭或禁用清理，已撤销的准备请求不能重新写入。自动档取不同尺寸时用对应键，在同一预算内淘汰。参考 Python 反哺分支与 moon135246 的预算策略，Swift 无主动预热队列。
- 命中时共享原帧引用，满足起播门槛可先交接；后台读取原 HEVC 依赖样本并沿用前缀采样相位，缓存覆盖区间跳过重复 vImage 转换和遮罩，继续按同一时间轴供帧。不保留额外 reader 或处理工作区作为缓存。接续统计记录新增可用帧或读完是否早于首个缺帧等待；性能面板对已发布帧、缓存及过渡参考图像按图像分配去重；原生合成的内部图形分配由进程 RAM 统计覆盖。24 MiB 是开头像素预算，其他播放帧、解码器和图形内存另计。
- 加载诊断附着当前 Animation，分别记录请求、首帧准备、起播就绪、主线程交接及当前帧首次提交图层；最终 Animation 复用已提交起播首帧时也登记本次交接时间。整段预加载的起播准备包含剩余全段。流式读取／转换／跳过及缺帧计数按该流累计，循环重开计入供帧等待；隐藏、停止和循环切换结束原等待区间，附带起播帧数、可播放余量及缓存复用数量。更新 FPS 按提交的不同 CGImage 计数，图层更新次数也包含同图像的几何变化；最长图像更新间隔仅在性能窗口打开时统计，隐藏重置基线，正常帧间隔和末帧保持也计入。这些指标是应用提交口径，不代表屏幕实际呈现时序；只保留有界数值，无逐帧日志、额外计时器或全库预热。
- 动作选帧使用单次 Timer，满帧跟随下一帧源时间戳，限帧节拍锚定动作时间轴；晚到回调不累加到下一帧期限。选帧用实际回调时刻与原定期限的较晚者，源时间轴比较容许 1µs 浮点误差，避免时钟换算导致回调略早时错过已到期帧。下一段准备期间按旧段循环时间换算，落地继续保持末帧；动作结束和 250ms 吸边召回参与最早期限选择。流式空队列恢复只通知一次，Decoder 按当前流身份核对，允许尚在续播的旧流；不依赖新加载请求 token 吞掉旧流唤醒。隐藏撤销 Timer，显示恢复；等待帧期间仍按当前档位频率检查鼠标命中，不忙等。

`StreamingAnimation.prepareForPlayback` 在加载任务内准备首帧与 capacity 帧后续队列，短片 EOF 提前就绪；准备过程中核对请求身份，失效则取消 reader 并放弃发布。随后沿用统一 publish 切换画面和时间轴，不再首帧一到就切换。旧流在目标准备期间继续供帧；整段预加载仍等待全段完成。没有跨动作常驻缓存、全库预热或额外固定等待时间。起播缓冲为解码较慢的设备留出准备时间，此改动保留为面向老设备的优化方向。用户在 agy 再次运行时使用 dev.6 仍复现停顿，P0 继续定位刷新和供帧瓶颈；M1 Air 的实际收益及 RAM 峰值待实测。

## 0.7.5-dev.4 · 动画加载交接

用户反馈手动随机／指定动画切换会先停住再播放，而自动播放正常；整段预加载未改善。`Decoder.load` 原先调用 `cancel()` 立即停止当前流；现在仅取消待完成 worker 并更新 generation，保留活动流供应旧画面。新片段首帧（流式）或全部帧（整段预加载）就绪后，由统一 publish 在主线程核对 generation，交付画面与时间轴，再停止旧流。过期预备流立即停止；失败保留当前画面并报告加载错误。

`cancel()`、configure 和 close 仍停止当前流。切换期间只重叠当前动画与正在准备的目标动画，不预热整套素材；整段预加载仍需等待目标片段解码完成，旧动画继续显示。吸边召回已有 pending 动作时直接播放目标，不先启动待机解码。默认缓冲、帧率和画质不改；没有加入姿势插值或交叉淡化。实际流畅度、快速连点及运行内存 (RAM) 峰值待用户验收。

手动 `preview` 仅在显隐状态实际变化时调用 `applyVisibility`，避免已可见时重建托盘菜单；先发起 `play`／吸边召回，再调用 `say` 排版气泡。自动入口不经过这段手动显示流程，手动与自动的差异继续按 P0 跟进。

## 动画与性能

当前 catalog 共 35 段 MOV，保留原动作清单的时长、缩放、偏移和位移参数。待机、第二待机、拖拽、落地采用去杂色及局部描边平滑后的素材：前三段各 96 帧／24 fps／4 秒，落地 48 帧／24 fps／2 秒，720×720。清理副本与原始 PNG 均保留。

性能页“动画效果改善 → 轮廓阴影”暂默认关闭，已有明确保存值保留。开启后使用 AppKit `NSWindow.hasShadow`，在图层状态更新后通过 `invalidateShadow()` 更新透明轮廓。设置持久保存，参与性能页恢复、导入导出及设置搜索；不生成描边位图、不添加帧缓存或刷新定时器。作者基线 `b102e73` 的 `Pet.paintEvent`／`draw_frame` 直接绘制素材，没有运行时描边或发光滤镜；轮廓阴影是可选显示效果，不修改素材内的轮廓线或颜色。dev.4 用户反馈开启时偶发黑点、关闭后消失，具体原因尚未定位。

新用户默认较高 512×512、12 帧后续缓冲、满帧播放，已有保存值保留。画质另有原画 720×720、中 384×384、低 256×256；缓冲可设整数 6～240，输入非法值在结束编辑时恢复 12；素材 FPS 上限可选“满帧 (≥ 24 FPS)”／20／15。满帧按素材 nominalFrameRate 与播放速度调度，当前 33 段为 24 fps、2 段为 30 fps，不插帧。FPS 上限与播放速度独立，时间轴和动作时长不改变。

流式读取在串行后台队列进行，首帧及约 250 ms 可播放余量就绪后交接，按视频 PTS 消费，缓冲满暂停读取。准备期间旧流续播，只准备当前请求；可选开头缓存复用已播放帧，不主动预热。帧图像与 Alpha 命中同步缩放，首帧边界映射到 512 逻辑画布；generation 屏蔽过期任务，退出等待当前解码结束。详细门槛、缓存预算和循环规则见现行动画约束。

“整段动画预加载”默认关闭；开启后完整读取当前动作再播放，同动作循环复用，切换动作重新载入，不预热整个素材库。启用后缓冲和常用动作开头缓存置灰并保留值。设置顺序为画质、帧率上限、缓冲帧数、常用动作开头缓存、整段预加载；具体文案以设置页源码为准。

当前默认 12 帧队列在 512×512 下，RGBA 图像及 Alpha 平面按紧密排列估算约 15 MiB（720×720 时约 29.7 MiB）；首帧、当前帧、在途帧及可选开头缓存另计。这只是像素估算，不是进程总运行内存 (RAM)。用户曾反馈旧版 dev.7 约 280～300 MB，不沿用为当前版本结果。

## 性能统计口径与窗口

统计默认关闭，只在窗口启用时采集。独立 NSWindow 默认位于主屏左上角，显示 Dock 图标，可最小化并从 Dock／菜单召回。左下角 pin 开关控制 floating／normal，默认置顶并记忆；右侧关闭与拷贝按钮同排。红灯和关闭按钮销毁窗口并停止采样，绿灯禁用。设置中开关窗口保留设置 key window。

固定布局实时显示更新 FPS、CPU 总体、运行内存 (RAM)、应用组 GPU 和本段缺帧等待次数，每秒只更新变化的值。“拷贝完整诊断”在点击时生成文本，包含动画耗时、帧缓冲、CPU 单核基准、压缩及 Swap、硬件和会话连接；系统 Swap、GPU 型号与桌面进程信息在生成报告时读取。

- 更新 FPS：SpriteView 提交给图层的不同 CGImage 数；几何更新不重复计入，HI／LO 为本次开启极值，包含暂停和隐藏。完整诊断另计包括几何变化的图层更新次数、最长图像更新间隔及请求到图层提交耗时；均为应用提交口径，不代表屏幕实际呈现。
- CPU：getrusage 进程累计 CPU 时间差分；总体占比除以逻辑核心数，单核基准以一个核心满载为 100%，允许超过 100%。不是最忙核心读数，也不对大小核算力加权。
- GPU：PROC_PIDCOALITIONINFO 与 coalition_info_resource_usage 的 gpu_time 差分，显示应用资源组口径，包括同组子进程；不等同于整机 GPU 饱和度。失败显示错误，不伪报零。
- 运行内存 (RAM)：TASK_VM_INFO.phys_footprint；压缩量单独读取 compressed。驻留帧按图像及 Alpha 字节估算，重复引用去重；系统图形／解码资源不包含在帧估算中。
- Swap：系统交换空间来自 vm.swapusage；本进程累计换入来自 ledger_swapins，并按返回结构长度判断字段是否存在。正数表明曾换入，零不排除已换出但未读回；不提供无法确定的本进程当前磁盘换出量。字节口径依据 [Apple XNU 实现](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/vm/vm_compressor.c)。
- 当前无应用自建的动画磁盘缓存，不把素材文件或会话文件算作缓存。
- 完整诊断分别列出 Codex／ChatGPT 桌面进程及只读同步状态、桌宠自身 CLI app-server 状态／PID／路径。

## 临时气泡与历史边界

“我还在留意进展…”与“让我看看额度…”的标题由 Bubble 显示层添加十帧盲文字符和一个空格，每 100ms 更新，只有盲文字符使用当前强调色，文字保持普通标签颜色。相同气泡正文更新不重建动画计时器；标题替换或隐藏时停止，关闭释放计时器。传入文本和 History 数据不加盲文字符。任务完成、失败及额度结果沿用各自展示，不把加载动画持久化。

## 气泡材质与设置交互

玻璃滑块图标来自系统符号库 capsule.on.rectangle.liquid.glass 与对应 fill，目录标记为 2026 新增；在 macOS 27 使用 NSImageView.dataWithPDF 导出资源，并在 macOS 26 从包内读取。没有窗口截图或视觉检查。符号 PDF 保留本地，不进 Git；导出工具追踪，构建将 glass-symbols 加入资源。

## 称呼与台词编辑

SettingsTemplateField 和独立的 SettingsTemplateEditor 仅用于“称呼与个性”，其余输入框仍使用系统编辑器。菜单保留剪切／拷贝／粘贴／全选；台词及特定称呼另有三种变量插入，名字字段没有分隔线或插入项；菜单文字用 Tab 和统一 NSTextTab 停靠点对齐。编辑时通过 NSLayoutManager 临时属性着色，非编辑时使用属性文本显示，保存／拷贝仍为纯文本；输入法组字期间不截断。指代符采用适配深浅模式的蓝／紫／橙文字与淡色底。

名字和称呼 20 字，问候与各类台词 120 字；计数器位于输入框右侧，与清空按钮同排；普通文字按 Swift Character 计数，每个变量整体计 1 字，达到上限为红色。既有值不在启动时截断，重新编辑时执行新上限，导入使用相同上限。“互动台词”的恢复默认仅清空 customLines；整页／全部恢复与导入导出包含任务进展、成功、失败、中断、等待回答、等待批准和额度查询七项台词。空状态台词使用内置默认值。示例台词将主人与角色名转换成对应指代符，实际气泡预览再展开。

任务执行中、成功、失败、中断／取消和额度查询中分别通过 PetPreferences.statusLine／taskResultLine 读取；只替换标题，不改模型正文、错误详情或历史任务文本。长标题高度由原生 cell 测量，计时文字与第一行原生基线对齐，标题区域右边界始终停在计时区域左侧。

## 待处理请求气泡

TaskAttention 将内置 requestUserInput 与外部公开 questions 映射到等待回答；命令／文件修改审批映射到等待批准。两项模板属于称呼与个性，遵循 120 字、指代符高亮、恢复默认与导入导出。等待时暂停文字流水，elapsed 继续由任务开始时间计算，气泡不自动消失。敏感请求保留整行高亮“转到 Codex”；内置审批召回原生请求窗口，外部审批在气泡窗查看详情并明确提交决定，保留 Codex 跳转入口。非敏感选择题的直接提交见下方 dev.17 说明。

内置普通进展更新不覆盖正在等待的请求；结束回答／批准时清理同会话的等待气泡，审批默认拒绝及取消输入后停止任务保留。外部同步以公开问题、item 等待状态和 turn 等待状态区分两类，读取 userMessage 时仅由 SQL 投影回答关联的问题标题，排除答案值。跨轮次按 questionItemId 移除已回答问题，后续普通进展不提前清除未回答问题，任务终态清除等待状态。

isSecret 标记的请求不在气泡显示问题、选项或输入值，包含敏感提问的外部 agentMessage 正文不进入同步结果。桌宠 Turn 仅新增可选的 sensitiveQuestionNotice／sensitiveInputNotice：分别显示“（已隐藏{桌宠名}的敏感信息提问）”与“（已隐藏{用户名}的敏感信息输入）”，旧历史无需迁移；只有提交后才记输入。输入值仅用于原生请求回复，不进入这些历史字段，外部答案值不由观察器读取。该规则依据明确的敏感请求标记，不将普通消息按关键词猜测为敏感输入，也不修改 Codex 原始记录。

### dev.17 问题交互与本机存储

非敏感问题使用原生单选、其他回答和补充输入；草稿仅存在当前请求内存中，关闭气泡保留，回答或请求结束后销毁。窗口允许拉伸并重排，右上角仍是累计用时，不设自动提交／消失倒计时。内置任务经原连接回复；桌面端由 DesktopQuestionReply 连接当前用户的 `.codex/ipc/ipc.sock`，按桌面端 v1 owner discovery / follower steer 路由发送带 questionItemId 的原格式回答。此接口依据本机已安装桌面端代码核对，不宣称为稳定公开 API；不改 Codex 配置、数据库或凭证，不自动重试提交。失败保留输入并提供原有转到 Codex 入口。已回答检测跨轮次只投影问题 ID，不读取答案。

高级页统计本应用数据目录、专用缓存目录和偏好文件，默认任务文件夹单列，百分比以三项总量为基数；文件大小统计跳过符号链接。清空本机数据只重置桌宠历史／同步副本及应用设置，保留任务文件、Codex 原始记录、凭证和跟随启动项。同步清除时间水位防止旧副本立即回填；清空磁盘缓存不冒称释放动画帧缓冲的运行内存 (RAM)。危险确认无默认回车操作。

### dev.18 问卷分页

QuestionForm 一次呈现一道题，导航保留输入，最后通过原会话提交非空回答。跳过仅改变本地表单，不写入空答案或伪造用户回复。多行文本共用 MessageEditor，发送与换行遵守 sendShortcut，提供灰色快捷键提示；左右 5pt 内缩为焦点边框留出空间。

问卷导航固定于气泡底栏；单题或全部跳过立即隐藏，已跳过题 ID 在 DesktopSync 内存中抑制提醒，重启清空。仅已填写答案送回 Codex，未接入原端跳过状态写入。可输入 PetWindow 按命中内容恢复箭头／文本光标，边缘保留缩放交互。

### dev.19 气泡位置

BubblePlacement.swift 统一消息气泡和临时回复窗的屏幕定位：屏幕可用区域内缩 8pt，以角色可见边界计算上下左右候选，当前方向无遮挡则保留，否则选择无遮挡候选；空间不足时选择最小遮挡并约束在屏幕内。气泡大小变化触发重排，普通正文更新且原位置仍安全时保留位置。拖拽、吸边与动画切换不关闭气泡；临时回复窗不把桌宠左键事件当作外部点击收起。

### dev.20 个性设置与变量迁移

TemplateSyntax.swift 将 {称呼}→{特定称呼}、{名字}→{用户名}、{桌宠}→{桌宠名}；仅限 customAddress、各 Template 键及 customLines。启动用独立迁移标记只执行一次，导入文件每次规范化；解析继续识别旧别名，用户名／桌宠名、历史与原始正文不迁移。每个变量作为一个计数单位，截断保持变量完整，替换结果不递归解析。

个性页保留原生文本框与系统菜单行为：剪切、拷贝、粘贴、全选；名字字段不插入变量。台词区域展开并换行，右侧清空和计数同排，达到上限红色；名字标签附变量色标和图标，桌宠名直接使用状态栏图标。特定称呼始终显示，由台词变量决定是否使用。

问候语通过 greetOnFirstAppearance 在每次进程启动后首次有画面且显示时触发一次。遵守互动气泡与安静模式，任务、其他气泡或输入窗已存在时跳过，不延迟补发；隐藏后召回不重播。以普通气泡显示角色名及问候正文，无 Codex／详情按钮，不写历史；空模板使用默认问候。

### dev.21 称呼来源

称呼来源单选已移除；customAddress 始终可编辑，留空沿用有效用户名。用户名为空时有效值为主人，默认台词及内置会话人格使用有效用户名；已有自定义台词保留。旧 addressMode 启动移除、旧设置导入忽略。

## 0.6.0 当前开发实现

### 数据来源与状态选取

本机桌面端协议来源为已安装 ChatGPT.app 26.1027.30824 的 app.asar（early-bootstrap-339-aea964a206c655e4.js、early-bootstrap-916-2f6483d5bfd826f1.js、app-initial 资源）。DesktopApprovalReader 复用 DesktopSocket，订阅 thread-stream-following-changed v1，接收 thread-stream-state-changed v11 的 snapshot／patches；这是当前安装版本的实现依据，不是稳定公开 API。

观察连接仅订阅执行中会话，不成为 writer；每 5 秒快照校准，增量核对 sourceClientId／baseRevision，超过 8 秒未确认的快照丢弃。DesktopRuntimeProjection 投影 requests、turns 和 turnHistory.history.entitiesByKey 中的请求身份与公开活动字段，不保留 reasoning.content、工具输出、用户输入或会话设置。停止观察关闭连接，删除本地会话不停止 Codex 任务。

TaskActivity 统一内置事件与外部实时／历史数据：思考读取公开 summary；读取、列目录和搜索读取 commandActions 的 type／name／path／query；调用工具显示 namespace／server 与 tool；文件修改显示路径。命令缺少结构化动作时显示原命令，不分析工具 arguments 推测含义。运行中工具优先于旧摘要，同阶段空摘要不覆盖已有摘要；摘要 item 完成不等于轮次结束，不切换为“思考摘要”占位标题。真实轮次完成后停止进展。

DesktopSync 每 0.2 秒调度实时接收，历史数据库最多每秒读取一次，标题仍每 5 秒补查；已获得的实时投影可清除旧数据库活动。概览每 0.2 秒刷新内存状态，无展示变化不重刷历史正文。以上是源码调度参数，端到端更新延迟尚未实测。

### 展示、尺寸与设置

任务概览中，进展位于执行中任务标题上方一行；MarqueeProgressField 以 Core Animation 重复同句，仅超宽时启用，末尾以同字体三个空格间距衔接下一遍首字、速度 28pt/s，内容改变重置，同内容保留相位。减少动态效果／关闭动态效果时静态渐隐；隐藏停动画，不随动画查库。进展不生成记录卡片，正文消息与待处理请求仍按真实消息／请求身份保存。

Pet 持有独立 progressToast 非激活 Bubble，自动小气泡默认开启，思考或工具活动变化自动触发，优先桌宠上方，默认停留 2 秒（1～10 秒）。同内容不重复弹出，变化原地更新并重计时；与主气泡重叠、待处理请求、手动翻阅、临时输入或额度展示时让位。结束、停止观察、隐藏及退出清理。自动宽度按文字在 280～360pt 基准内扩展，整窗高度最多 180pt，均随气泡比例缩放，再受屏幕可用区域限制；标题单行并保留完整悬停，超出正文滚动。上限也优先于短气泡自定义宽高比，不限制审批和普通消息。

外观“气泡形状”提供 bubbleAspectEnabled（默认关闭）和 bubbleAspectRatio（0.6～3.0，初始 1.5）。开启后消息／进展气泡按宽高比布局，操作区最低尺寸及屏幕边界优先；问卷手动尺寸优先，额度继续按内容排版。设置变更刷新既有气泡，不改变任务或历史。

消息与提醒中，“气泡卡片与任务概览”紧接“显示哪些消息”；showThinkingProgress、showToolProgress 默认开启，progressToastEnabled 默认开启。“进展小气泡停留时间”在“停留时间”组最后，思考与工具共用时长。个性页 taskThinkingTemplate／taskToolTemplate 默认分别为“{桌宠名}正在思考”／“{桌宠名}正在调用工具”。这些设置接入原有搜索、导入导出和恢复。

### 气泡窗内直接审批

DesktopApproval 在明确点击后新建 socket，先 thread-owner-discovery，再读取 owner 最新快照，核对原请求 ID、method、turnId、操作详情和执行中轮次。命令／文件修改调用 thread-follower-command-approval-decision v1／thread-follower-file-approval-decision v1，决定为 accept／decline；权限调用 thread-follower-permissions-request-approval-response v1，scope 为 turn。发送后读取快照确认请求移除；缺少操作详情不能同意，超时／不完整回执保留待确认且不自动重发。ApprovalPresentation 绑定原表单，迟到回执不更改后来请求。

气泡窗先展示审批理由，再展示命令、工作目录等完整可滚动详情。DesktopApproval.detailSections 按显式顺序保存原文字段，details 仍用于提交前内容核对。ApprovalText 渲染理由中的 Markdown 代码块；独立命令直接交给 CodeBlockRendering（shell），结构化权限等使用 JSON 代码框，原命令不经过 Markdown 解析。底部保留等宽拒绝／允许按钮及转到 Codex。拒绝使用淡红底、动态红字和 xmark，允许使用淡绿底、动态绿字和 checkmark；文字和图标同时区分动作，深浅模式采用系统语义色与 labelColor 混合提高文字对比。按钮无默认操作、快捷键、键盘焦点或键盘激活，保留辅助功能显式操作。隐藏／关闭不提交决定。

消息页“气泡窗审批按钮顺序”使用 approvalButtonOrder：rejectLeft（默认）或 allowLeft，仅交换两个按钮位置，不改动作。内置原生审批对话框默认拒绝，Codex 自身界面不受此选项影响。敏感问题仍跳转 Codex，不展示答案。

### 原生代码块

MarkdownText 读取 Foundation 的 codeBlock 语义，CodeBlockRendering 使用一列单个 RoundedCodeBlock（NSTextTableBlock 子类）承载语言头与连续代码正文，通过公开 drawBackground 绘制整块圆角普通背景与细边界；原生按钮仅提供完整复制。基础词法着色覆盖常见语言的关键词、字符串、注释、数字和函数名，未知语言按纯文本显示。代码保持在文本存储中，缩进、空行、选择、历史搜索及未闭合围栏的流式正文保留；没有远程依赖或代码执行。

### 本机文件链接召回访达

## 文件引用与修改摘要（0.7.0-dev.2）

- `CodexFileCitation` 在共用 `MarkdownText` 入口将 `:codex-file-citation{path="…" ...}` 转成文件名链接，按绝对路径构造 URL；不按扩展名限制文件类型。使用 Foundation 源码位置排除代码块、行内代码及已有链接；不完整或缺少有效路径的标记保留原文，不改历史源文本。
- Markdown 链接、图片入口、imageGeneration 保存链接、文件产物引用和修改摘要最终共用 `MessageTextView → MessageFileLink → FinderFileReveal`。相对路径使用消息所属会话 cwd，点击时才检查文件；网页等非本机链接交给系统。`sandbox:` 保持下载提示，不当成本机路径。
- `FileEditSummary` 由内置事件与外部只读记录共用，只统计 completed 的 fileChange。内置按 item ID 替换，轮次内同路径合并；新增／删除文件按完整 diff 文本行数统计，update 按 diff hunk 的 +／− 行统计。统计为本轮已完成修改的累计行数，不代表最终 Git 净差异。无 diff 时只显示路径，不伪造 0。
- `FileEditRendering` 输出共用原生摘要：标题与总增减同排，总计右对齐，默认展示 3 项；文件路径使用共用超链接外观、文件名用中等字重突出，右侧红绿计数按总计与各文件计数的最大文字宽度分配空间，可展开／收起。无撤销或 diff 窗口。

### Codex 重连状态与中文错误

内置 TaskMessageAccumulator 接收 error.error 与外层 willRetry；CodexConnectionProgress 临时保存本轮连接状态，优先于普通工具进展。外部 DesktopRuntimeProjection 仅追加公开错误字段 message／willRetry／errorInfo，DesktopApprovalReader 按会话及轮次记录状态；正文和原始推理内容仍不投影。模型正文／公开摘要的增量只用于确认恢复，不额外留存正文。同批增量按错误与恢复的先后判定，首次快照已有错误之后的模型进展时不重播旧重连。

重连使用 wifi.exclamationmark 与橙色“正在重新连接 N/M…”，N/M 只从原消息提取，未提供次数则省略。恢复需收到真实模型进展，wifi 与绿色“连接已恢复，继续处理。”保留约 2 秒，再显示普通进展。网络错误停止重试使用 wifi.slash 与红色“重新连接失败，Codex 已停止重试。”，最终气泡下方为“检查你的网络或节点环境。”。重试不改变任务执行状态，最终失败由轮次终态确认，秒表不重置。主气泡有本轮内容时只更新进展；没有时复用本轮 connection-status 卡片，不按每次重试增加卡片，不抢问卷、审批与翻阅中的卡片。

TaskActivityAppearance 使用语义橙／绿／红，呼吸仅对图标添加 Core Animation 透明度动画，不增加计时器；隐藏时移除，关闭 bubbleMotion 或启用减少动态效果时静态。普通短进展小气泡布局不变，连接状态使用主气泡与概览。连接状态不拼入助手正文、工具步骤或历史，也不因纯显示变化额外保存历史。

CodexErrorMessage 优先读取结构化 codexErrorInfo／errorInfo／code／type，并识别明确的错误原文。覆盖模型与当前连接方式不匹配、模型无访问权限、订阅额度、API 余额／预算、会话预算、限流、身份验证、服务繁忙、上下文超限、请求／附件设置、权限及已有 writer。HTTP 429 不直接推断余额或订阅额度耗尽；未知错误显示中文通用说明，原始错误保留在技术详情与历史。内置协议连接断开单独提示桌宠未能继续接收状态，不宣告 Codex 已停止上游重试；外部观察失败继续使用现有同步错误入口。

错误协议参考：[Codex App Server 的 Errors](https://learn.chatgpt.com/docs/app-server#errors)、[官方 Codex 协议 schema](https://github.com/openai/codex/blob/main/codex-rs/app-server-protocol/schema/json/v2/ThreadListResponse.json)。本轮未编译、未运行真实网络故障或请求，显示与事件接入待用户实机验收。
