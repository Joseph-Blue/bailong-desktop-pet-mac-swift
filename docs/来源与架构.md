# 来源与架构

## 0.3.0 当前实现

本版由原生动画开发分支合并到本地 main，未推送远端、未创建 Release。最低 macOS 14，本次构建 Apple Silicon 完整应用，Intel 源码构建入口保留。

| 层次 | 实现 | 入口 |
|---|---|---|
| 界面与交互 | Swift + AppKit，原生窗口、菜单、设置、气泡和历史 | Sources/BailongPet |
| 动画 | HEVC with Alpha MOV → AVAssetReader BGRA → Core Image Lanczos → RGBA CGImage | Resources.swift、StreamingAnimation.swift、Pet.swift |
| PNG 素材接入 | Core Image → AVAssetWriter ProRes 4444 → 系统 avconvert 透明 HEVC | Tools/NativeHEVC/ApplyPNGRepairs.swift |
| 性能设置与统计 | AppKit、getrusage、Mach task_info、Metal 设备信息及 GPU 资源组计数 | Settings.swift、Diagnostics.swift、GPUStatistics.swift |
| Codex 任务 | 本机 CLI app-server 的 JSON 行协议，子进程和审批独立管理 | Codex.swift、ChatController.swift |
| 外部只读观察 | 本机 SQLite 与公开任务字段，只读同步 | DesktopSync.swift |
| 跟随启动 | 同架构独立 helper，按 bundle identifier 与启动周期识别 | FollowMonitor.swift、Tools/FollowHelper/main.swift |

运行、打包和现行素材工具均不依赖 FFmpeg；旧 WebM 转码入口与工具已删除。原始 WebM、原始及修复 PNG、旧素材备份留在 local-assets，默认忽略，不作为运行资源。没有 Python／PySide6 运行时。

## 动画与性能

当前 catalog 共 35 段 MOV，保留原动作清单的时长、缩放、偏移和位移参数。待机、第二待机、拖拽、落地采用去杂色及局部描边平滑后的素材：前三段各 96 帧／24 fps／4 秒，落地 48 帧／24 fps／2 秒，720×720。清理副本与原始 PNG 均保留。

默认清晰 512×512、24 帧后续缓冲、满帧播放。画质另有 384×384、256×256；缓冲可设整数 6～240，输入非法值在结束编辑时恢复 24；FPS 上限可选满帧／30／24／20／15。满帧沿用 30 Hz 调度播放当前 24／30 fps 素材，不插帧。FPS 上限与播放速度独立，时间轴和动作时长不改变。

流式读取在串行后台队列进行，首帧完成后开始播放，按视频 PTS 消费，缓冲满暂停读取。保留首帧、当前帧及一个在途帧；容量不跨动作预读。帧图像与 Alpha 命中同步缩放，首帧边界映射到 512 逻辑画布，菜单栏裁剪映射回实际像素。generation 屏蔽过期任务，循环回绕的 epoch 丢弃旧循环结果，退出等待当前解码结束。

“整段动画预加载”默认关闭；开启后完整读取当前动作再播放，同动作循环复用，切换动作重新载入，不预热整个素材库。启用后缓冲整行置灰，关闭恢复保存值。说明固定为“不推荐，会显著增加运行内存 (RAM) 占用。”设置顺序为画质、帧率上限、缓冲帧数、整段预加载。

默认画质下 24 帧图像及 Alpha 平面约 30 MiB，这只是像素估算，不是进程总运行内存 (RAM)。用户曾反馈 dev.7 约 280～300 MB，该值属于旧版 256×256 整段解码实测，不沿用为当前版本结果。

## 性能统计口径与窗口

统计默认关闭，只在窗口启用时采集。独立 NSWindow 默认位于主屏左上角，显示 Dock 图标，可最小化并从 Dock／菜单召回。左下角 pin 开关控制 floating／normal，默认置顶并记忆；右侧关闭与拷贝按钮同排。红灯和关闭按钮销毁窗口并停止采样，绿灯禁用。设置中开关窗口保留设置 key window；不设置自定义悬停说明，高度按内容收紧。

- FPS：SpriteView.draw 完成后的不同画面数，重复绘制不重复计入；每秒采样，保留 60 点，HI／LO 为本次开启极值，包含暂停和隐藏。不是显示器扫描刷新率。
- CPU：getrusage 进程累计 CPU 时间差分；总体占比除以逻辑核心数，单核基准以一个核心满载为 100%，允许超过 100%。不是最忙核心读数，也不对大小核算力加权。
- GPU：PROC_PIDCOALITIONINFO 与 coalition_info_resource_usage 的 gpu_time 差分，显示应用资源组口径，包括同组子进程；不等同于整机 GPU 饱和度。失败显示错误，不伪报零。
- 运行内存 (RAM)：TASK_VM_INFO.phys_footprint；压缩量单独读取 compressed。驻留帧按图像及 Alpha 字节估算，重复引用去重；系统图形／解码资源不包含在帧估算中。
- Swap：系统交换空间来自 vm.swapusage；本进程累计换入来自 ledger_swapins，并按返回结构长度判断字段是否存在。正数表明曾换入，零不排除已换出但未读回；不提供无法确定的本进程当前磁盘换出量。字节口径依据 [Apple XNU 实现](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/vm/vm_compressor.c)。
- 当前无应用自建的动画磁盘缓存，不把素材文件或会话文件算作缓存。
- 分开显示 Codex／ChatGPT 桌面进程及只读同步状态、桌宠自身 CLI app-server 状态／PID／路径；连接不等同于登录或配额有效。

## 临时气泡与历史边界

“我还在留意进展…”与“让我看看额度…”的标题由 Bubble 显示层添加十帧盲文字符和一个空格，每 100ms 更新。相同气泡正文更新不重建动画计时器；标题替换或隐藏时停止，关闭释放计时器。传入文本和 History 数据不加盲文字符。任务完成、失败及额度结果沿用各自展示，不把加载动画持久化。

## 来源与行为依据

原作：[jingh12312-rgb/bailong-desktop-pet](https://github.com/jingh12312-rgb/bailong-desktop-pet)，v0.5.1／b102e734f20bb50889af12df5778f1499109f41b。只读参考 pet.py、movement.py、video_frames.py、chat_backend.py、desktop_task_sync.py 及跟随启动相关函数，不修改参考仓库，不运行 Windows 程序。

角色动画来自原作发布包，图标由待机画面制作；用户说明已获原作者同意进行素材修复及反哺。该范围不扩展为项目或素材的全面再许可，不擅自添加许可证。点击音效沿用原作 app/sounds/click.wav 及来源说明；原始出处未因本地处理而改变。SQLite 使用系统动态库，Apple 框架与系统编码工具由系统提供。

旧 FFmpeg 链路只属于素材历史与 0.2.x 历史记录，当前不分发其二进制，也没有调用入口。历史产物保留本地，不据旧工具许可描述当前原生包。

内置任务与外部观察分开；停止、默认拒绝审批、历史保护和进程回收保留。外部工具中间失败不单独生成失败提醒，保留最终失败与待处理请求。跟随启动只识别 Codex／ChatGPT 桌面应用，拒绝临时 AppTranslocation 路径，用户主动配置，不自动注册系统启动项。

## 构建与交付证据

应用版本以根目录 VERSION 为准；构建为 `scripts/build.sh arm64`，产物在 `dist/native-hevc/0.3.0/arm64`。主应用与 helper 同架构，包内只带运行素材、声音和图标，不带原始 PNG／WebM、ProRes 中间文件或用户数据。

0.3.0 Apple Silicon 主程序／helper 编译通过，PNG 原生编码工具编译通过。此次没有重新转码已选定素材，也没有自动启动应用、截图或做视觉／冒烟验收；新 PNG 编码输出、盲文动画和窗口交互效果尚未运行验收。过去的素材首帧验证记录保留在本地实施日志，不冒充新工具验收。

下一项功能：检查更新。当前没有网络版本查询、自动下载或安装实现；具体实现单独开展。
