# 开发资源获取

适用于 `joseph/dev`，当前资源基线为 0.6.2，源码版本以根目录 VERSION 为准。资源 ZIP 与应用安装包分开：本分支不提供开发版 App 下载。

## 推荐：解压开发资源包

资源包文件名：`bailong-dev-assets-2026-11-02.zip`。包含完整运行资源及原生动画工具使用的 `samples.json`，不需要开发者重新转换动画。

**[下载开发资源 ZIP（约 111 MiB）](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/download/dev-assets-2026-11-02/bailong-dev-assets-2026-11-02.zip)** · [资源发布页](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/tag/dev-assets-2026-11-02)

该页面仅发布开发资源，标记为 Pre-release，不设为 Latest；不会进入应用的正式版本更新检查。

拿到 ZIP 后，在仓库根目录执行：

```sh
/usr/bin/ditto -x -k "$HOME/Downloads/bailong-dev-assets-2026-11-02.zip" .
```

解压直接得到 `local-assets/` 和 `DEV-ASSETS.md`。已有同名文件会被替换；自定义过的素材先另存副本。

```text
local-assets/
  native-hevc/catalog/
    素材清单.json
    samples.json
    透明HEVC/                    # 35 段 MOV
  sounds/
    click.wav
    来源.txt
    Kenney-License.txt
  glass-symbols/
    capsule.on.rectangle.liquid.glass.pdf
    capsule.on.rectangle.liquid.glass.fill.pdf
  BailongPet.icns
  openai-logo.png
  资源来源.md
```

`素材清单.json` 包含动作路径、时长、缩放和位移等运行参数，应与整套 MOV 一起使用。`samples.json` 是预览与素材接入元数据；其中 `sourceFile` 记录制作来源，不是运行时要打开的文件。包内将本工程绝对来源路径改写为相对路径，保持其他字段不变。

## 备选：从现有正式版 App 提取

没有资源 ZIP 时，可从 [0.6.2 正式版](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/tag/白龙桌宠Swiftv0.6.2) 的 App 提取运行资源。选择发布附件中的 `bailong-desktop-pet-v0.6.2-macos-apple-silicon.zip`，不是 GitHub 自动生成的 Source code ZIP。

解压后无需安装、启动或修改这个 App。访达右键 `白龙桌宠Swift.app` →“显示包内容”→ `Contents/Resources`，对应关系如下：

| App 包内路径（相对 Contents/Resources） | 仓库目标 |
| --- | --- |
| `outputs/白龙桌宠素材/素材清单.json` | `local-assets/native-hevc/catalog/素材清单.json` |
| `outputs/白龙桌宠素材/透明HEVC/` | `local-assets/native-hevc/catalog/透明HEVC/` |
| `sounds/`（整个目录） | `local-assets/sounds/` |
| `glass-symbols/`（整个目录） | `local-assets/glass-symbols/` |
| `BailongPet.icns` | `local-assets/BailongPet.icns` |
| `openai-logo.png` | `local-assets/openai-logo.png` |

也可在仓库根目录执行以下命令，把 `pet_app` 改成实际解压位置：

```sh
(
  set -eu
  pet_app="$HOME/Downloads/白龙桌宠Swift.app"
  pet_resources="$pet_app/Contents/Resources"
  mkdir -p local-assets/native-hevc/catalog
  /usr/bin/ditto "$pet_resources/outputs/白龙桌宠素材" local-assets/native-hevc/catalog
  /usr/bin/ditto "$pet_resources/sounds" local-assets/sounds
  /usr/bin/ditto "$pet_resources/glass-symbols" local-assets/glass-symbols
  cp "$pet_resources/BailongPet.icns" local-assets/BailongPet.icns
  cp "$pet_resources/openai-logo.png" local-assets/openai-logo.png
)
```

这份拷贝可供 `build.sh` 打包及 `run-dev.sh` 运行。正式 App 没有 `samples.json`，因此独立动画预览与 PNG 替换工具仍需从开发资源包补齐它。不要用空 JSON 代替。当前原生应用使用透明 HEVC；0.2.1 的 WebM 资源不能直接放入此目录。

## 0.7.5-dev.2 新增桌宠模板图

现有资源 ZIP 与 0.7.4 及更早 App 不包含 `pet-status-template.png`。本轮图片尚未随资源包发布，需另行取得用户提供的透明 PNG；旧资源的提取步骤继续适用于其余资源。原图保留在本地，执行以下离线工具生成本轮新增文件：

```sh
mkdir -p .build/resource-tools
xcrun swiftc -O Tools/PrepareStatusIcon/main.swift -o .build/resource-tools/PrepareStatusIcon
.build/resource-tools/PrepareStatusIcon /绝对路径/新托盘原图.png local-assets/pet-status-template.png
```

工具只清除极淡 Alpha 和孤立杂点、裁切可见边界；显示层等比居中到 18pt。`build.sh` 将该图加入包内 Resources；从包含新图的 App 提取时，额外复制 `Contents/Resources/pet-status-template.png` 至 `local-assets/`。图像不加入 Git。

## 编译环境

安装 Apple Command Line Tools 或 Xcode 的对应工具链。安装及检查命令如下：

```sh
xcode-select --install
xcrun --show-sdk-version
xcrun swiftc --version
```

已有工具链时无需重复安装。[Apple 安装说明](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools/)。

编译入口共用 scripts/swift-environment.sh，按实际 SDK 选择编入能力：27+ 为 full，26 为 glass，更早为 plain；SDK 至少 14，旧 SDK／旧工具链的完整兼容仍以实际编译结果为准。SDKROOT 可指定已安装 SDK，BAILONG_BUILD_PROFILE 可显式选择 auto／full／glass／plain。运行目标保持 macOS 14，运行时仍检查外观 API 可用性。

资源到位后，在仓库根目录选择执行：

```sh
./scripts/run-dev.sh --build-only  # 仅编译开发可执行文件，不启动
./scripts/build.sh arm64          # 打包 Apple Silicon App
./scripts/build.sh x86_64         # 按需打包 Intel App
./scripts/run-dev.sh              # 编译后运行开发版本
```

`--build-only` 仅生成 `.build/dev/BailongPetDev`，不更新已有 App。`build.sh` 输出到 `dist/<VERSION>/<架构>/白龙桌宠Swift.app`，会替换同版本同架构产物；显式构建档位额外存入 <档位>/ 子目录；launch.command 打开默认目录。开发编译缓存核对 SDK、工具链及能力，不跨环境复用。

默认构建 Apple Silicon；0.7.4 提供 Apple Silicon 包与 Intel 社区测试包。Intel 构建需显式选择 x86_64，Intel Mac 实机验收尚未完成，见 [待办](../todo.md)。

## 只有制作素材时才需要的工具

普通源码开发直接使用资源包。以下工具用于更换资源，不是首次构建的必经步骤。

### 角色动画

该 2026-11-02 资源包保留当时的完整 35 段透明 HEVC，包含当时已修复的待机、第二待机、拖拽和落地素材；源码版本变化不代表资源包已更新。原始 WebM、透明 PNG 帧序列及修复中间副本不在此包中。

拥有对应透明 PNG 后，可使用 [原生素材工具](../Tools/NativeHEVC/README.md) 替换已支持的动作：以 AVAssetWriter 写入 ProRes 4444，再用系统 avconvert 编码 HEVC Alpha。当前工具用于已有 catalog 的局部替换，不是从空目录生成全部 35 段动画的通用工具。

### 应用图标

直接使用包内 `BailongPet.icns`。若要从自己的透明 PNG 生成：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/GenerateAppIcon/main.swift -o .build/resource-tools/GenerateAppIcon
.build/resource-tools/GenerateAppIcon /绝对路径/角色.png local-assets/custom-icon.iconset
/usr/bin/iconutil -c icns local-assets/custom-icon.iconset -o local-assets/BailongPet.icns
```

### 玻璃符号

包内已有两份 PDF，构建时直接复制。重新导出需要提供这些符号的 macOS 27 系统；工具不创建交互窗口：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/ExportGlassSymbols/main.swift -framework AppKit -o .build/resource-tools/ExportGlassSymbols
.build/resource-tools/ExportGlassSymbols local-assets/glass-symbols
```

### 音效与 OpenAI 标志

复制完整 `sounds/`，同时保留来源及现有许可文件；当前 `来源.txt` 记录点击音为程序合成。OpenAI 标志直接复用包内 `openai-logo.png`，无需开发者另行读取已安装的 Codex App。

角色素材来源、图标制作与组件说明见 [来源与架构](来源与架构.md)。资源包保留原有来源说明，不新增统一素材许可证。
