# 开发资源获取

本文适用于 `joseph/dev` 开发分支（当前源码版本见 [VERSION](../VERSION)）。开发素材包的版本独立于应用版本号，由 `scripts/resource-manifest.json` 指定。

## 1. 当前开发素材包

- **当前版本**：`bailong-dev-assets-2026-11-10.zip`
- **导入内容**：35 段透明 HEVC 角色动画、状态栏与历史双版本单色模板头像、应用图标、点击音效、液态玻璃滑块符号 PDF、素材工具元数据（`samples.json`）及来源说明。

当前素材包已发布，大小为 117,730,879 字节。新检出的开发分支可用 `--download-resources` 下载。[11 月 10 日素材 Pre-release](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/tag/dev-assets-2026-11-10)

11 个供应商 PNG 小图标随源码存放在 `Assets/ProviderIcons/`，来源与许可见[第三方许可](../第三方许可.txt)。开发程序直接从该目录读取，App 构建时复制到 `Contents/Resources/`。

导入完成后，`local-assets/` 目录结构如下：

```text
local-assets/
  native-hevc/catalog/

    samples.json           # 独立预览与 PNG 替换工具元数据（不打入正式 App）

  BailongPet.icns

  pet-avatar-template.png  # 设置与历史界面细节版单色模板
  资源来源.md
```

## 2. 素材导入与构建命令

```sh
# 从本地 ZIP 导入缺失素材并构建 Apple Silicon App
./build.command --resources-zip /绝对路径/bailong-dev-assets-2026-11-10.zip

# 覆盖同名素材（旧文件自动备份至 .build/resource-import/backup-<标识>/）
./build.command --resources-zip /绝对路径/bailong-dev-assets-2026-11-10.zip --replace-resources

# 从 GitHub 下载当前检出的清单所指定的已发布版本并构建
./build.command --download-resources
```

- **校验规则**：导入前脚本会先解压至临时目录，按 `scripts/resource-manifest.json` 校验文件完整性、非空字节与 JSON 语法，校验通过后才写入 `local-assets/`。
- 导入只复制当前清单所需的文件。素材包内随旧版提供的 OpenAI 图标由脚本跳过，构建使用源码目录里的副本。
- **终端交互**：无参数双击 `build.command` 时，若本机缺少素材且当前素材版本已发布，终端会展示原作者信息与下载链接，输入 `Y` 下载导入，输入 `N` 查看手动下载和导入命令。素材版本尚未发布时，终端提示导入本地 ZIP。`--check` 或非交互环境（`BAILONG_INTERACTIVE=0`）不自动下载。

## 3. 编译环境与构建档位

本项目仅依赖系统自带的 Apple Command Line Tools（或 Xcode），无需安装 Homebrew、Python 或 FFmpeg。

- **环境自检**：缺少开发工具时，交互模式下输入 `Y` 会调起系统 `xcode-select --install` 安装弹窗；也可参考 [Apple 命令行工具安装指南](https://developer.apple.com/cn/documentation/xcode/installing-the-command-line-tools) 或前往 [Apple Developer 下载页](https://developer.apple.com/download/all/?q=command%20line%20tools) 获取对应系统版本的安装包。
- **路径与 SDK**：工具链路径异常可参照 [命令行工具路径配置说明](https://developer.apple.com/cn/documentation/xcode/configuring-command-line-tools-settings) 修正；若当前终端残留了失效的 `SDKROOT` 或 `DEVELOPER_DIR` 环境变量，脚本会直接给出清理命令。SDK 与系统版本对应关系见 [Xcode 系统要求](https://developer.apple.com/cn/xcode/system-requirements)。

常用入口命令：

```sh
./build.command --check          # 检查编译工具链与运行素材（不构建 App）
./build.command                  # 构建 Apple Silicon App
./build.command x86_64           # 构建 Intel App
./run-dev.command --build-only   # 仅编译开发二进制（无需运行素材）
./run-dev.command                # 增量编译并启动，显示协议、会话和逐段动画
./run-dev.command --monitor      # 收起逐段动画明细
./run-dev.command x86_64         # 启动 Intel 开发程序
./launch.command                 # 直接启动 dist/ 下对应本机架构的已构建 App
```

构建脚本会按本机 SDK 版本自动判定编译档位（可通过 `BAILONG_BUILD_PROFILE=full|glass|plain` 显式指定），主程序与跟随启动 helper 始终使用同一工具链与档位：

| 档位 | 编译要求 | 运行时界面表现（最低部署目标均为 macOS 14） |
| --- | --- | --- |
| `full` | SDK 27+ | 支持液态玻璃材质（macOS 26+）及菜单项图标常显（macOS 27+） |
| `glass` | SDK 26+ | 支持液态玻璃材质（macOS 26+），菜单图标沿用系统默认行为 |
| `plain` | SDK 14+ | 使用标准窗口材质，菜单图标沿用系统默认行为 |

- **输出路径**：`build.command` 默认输出至 `dist/<VERSION>/<架构>/`，显式指定 `BAILONG_BUILD_PROFILE` 时输出至 `dist/<VERSION>/<架构>/<档位>/`。Intel Mac 无参数双击脚本时，输入 `1` 可切换构建 `x86_64` 产物。
- **开发运行与退出**：`run-dev.command` 启动后会打印当前进程 PID；按下 `^C` 时先发送 `SIGTERM` 请求应用完成淡出与连接清理，同时显示 5 秒倒计时，进程提前退出即刻收尾，超时仅对该 PID 发送 `SIGKILL`。编译过程实时输出阶段耗时与编译器诊断，退出后自动清理临时文件。

### 终端监视

无参运行 `./run-dev.command` 即可从启动握手开始查看监视。按 **M** 暂停或恢复，按 **A** 收起或展开逐段动画，无需回车。恢复监视时显示当前连接、待回执请求和活跃轮次，并沿用暂停前的动画明细开关。

- **app-server** 显示子进程与握手、发出的 RPC 方法和编号、回执耗时、超时及错误码。轮次和工具项目记录开始与结束，服务端审批或问卷请求与客户端应答按服务请求编号对应。
- **桌面 IPC** 显示主动回复、插话、问卷和审批提交使用的方法、版本与回执。**桌面观察** 显示外部轮次和操作类别变化，可与气泡实际显示的状态对照。
- **动画** 默认显示逐段交接，包括请求到就绪、就绪到交接、交接到图层的耗时和上段等帧统计。收起明细后仍显示加载失败。使用 `--monitor` 可从启动时收起动画明细。

记录按本机时间、级别、来源和事件排列。表头和数据共用 Tab 列。标题为粗体紫色，来源列以青色标记 app-server、紫色标记桌面通道、亮蓝色标记动画、绿色标记气泡。级别列用青、绿、黄、红区分信息、确认、警告和错误。设置 `NO_COLOR=1` 可关闭配色。保存本次标准输出（含启动脚本信息）可用：

```sh
./run-dev.command > bailong-monitor.log
```

## 4. 打包与替换素材（仅维护素材时使用）

日常功能开发直接导入上述素材 ZIP 即可；以下脚本与工具仅在更新素材或重新打包 `dev-assets` 时使用。

### 打包开发素材 ZIP

```sh
./scripts/package-resources.sh
```

脚本依据 `scripts/resource-manifest.json` 收集 `runtime`（App 运行必需项）与 `development`（素材工具元数据及来源文档）文件，自动将元数据中的本机绝对路径脱敏为相对路径，在本地生成带 `DEV-ASSETS.md` 与 `RESOURCE-MANIFEST.json` 的素材包（不自动覆盖同名 ZIP，也不触发上传）。

### 局部替换透明 HEVC 动画

若对特定动作重绘或修整了 720×720 透明 PNG 帧序列，可调用 [原生素材工具](../Tools/NativeHEVC/README.md) 将 PNG 序列经 `AVAssetWriter`（ProRes 4444）与系统 `avconvert` 重新编码为透明 HEVC MOV，并在校验通过后原子替换当前 catalog 中对应的动作文件。

### 重新生成应用图标与玻璃符号

使用自定义透明角色 PNG 生成 `.icns` 图标：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/GenerateAppIcon/main.swift -o .build/resource-tools/GenerateAppIcon
.build/resource-tools/GenerateAppIcon /绝对路径/角色.png local-assets/custom-icon.iconset
/usr/bin/iconutil -c icns local-assets/custom-icon.iconset -o local-assets/BailongPet.icns
```

在 macOS 27 系统上重新导出液态玻璃滑块符号 PDF：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/ExportGlassSymbols/main.swift -framework AppKit -o .build/resource-tools/ExportGlassSymbols
.build/resource-tools/ExportGlassSymbols local-assets/glass-symbols
```

音效目录 `local-assets/sounds/` 与图标 `local-assets/openai-logo.png` 直接随素材包维护，更新音效时请同步保留目录内的来源与许可说明文件。各素材与图标的详细出处见 [来源与架构](来源与架构.md)。
