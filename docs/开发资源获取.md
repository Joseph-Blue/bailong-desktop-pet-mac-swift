适用于 `joseph/dev`，当前源码 0.8.0-rc.4。资源版本独立于应用版本，记录在 `scripts/resource-manifest.json`。

下载地址：[开发素材包 2026-11-10](https://github.com/Joseph-Blue/bailong-desktop-pet-mac-swift/releases/tag/dev-assets-2026-11-10)。素材使用独立 Pre-release，不影响应用正式版更新。

## 导入与构建

```sh
./build.command --resources-zip /绝对路径/bailong-dev-assets-2026-11-10.zip
```

此命令先导入，再构建。默认只补齐缺失文件；需要更新同名文件时追加 `--replace-resources`。被替换文件保存在 `.build/resource-import/backup-<标识>/`，其余本地素材不动。ZIP 先解压到临时目录，依据仓库清单检查再导入；清单不完整、空文件、JSON 错误会停止导入。

双击 `build.command`，素材检查前先说明原作作者和仓库。缺少素材时，脚本展示本项目 GitHub Release 下载地址，并提醒检查终端网络、代理设置和节点；输入 Y 下载并补齐，输入 N 显示手动下载、导入命令，再按任意键结束。

本地 ZIP 可用 `--resources-zip` 导入；显式传入 `--download-resources` 表示直接请求下载，不再询问。非交互调用与 `--check` 不自动下载。下载显示进度条、百分比、已下载／总大小和速度，使用原有文件、清单及格式检查，不增加 SHA-256 校验。

```text
local-assets/
  native-hevc/catalog/
    素材清单.json
    samples.json
    透明HEVC/*.mov
  sounds/click.wav
  sounds/来源.txt
  sounds/Kenney-License.txt
  glass-symbols/*.pdf
  BailongPet.icns
  openai-logo.png
  pet-status-template.png
  pet-avatar-template.png
  资源来源.md
```

`素材清单.json` 与动画配套使用。`samples.json` 只供独立预览及素材工具使用；其中 sourceFile 为制作来源，不是运行依赖。托盘图为笑眼简化版，设置／历史图为细节版，均为透明单色模板。

## 环境与入口

缺少 Apple 开发工具时，脚本说明由 Apple 官方系统安装窗口下载 Command Line Tools（含 Swift 编译器和 macOS SDK）。输入 Y 打开安装窗口；输入 N 显示手动命令 `xcode-select --install`，再按任意键结束。安装完成后重新运行构建入口。`--check` 和非交互调用只显示手动命令。工具路径错误时在 Xcode → Settings → Locations 中选择 Command Line Tools；设置过 SDKROOT 或 DEVELOPER_DIR 时检查相应变量。无需 Homebrew、Python 或 FFmpeg。

```sh
./build.command --check                 # 检查环境与运行资源
./build.command                        # Apple Silicon App
./build.command x86_64                  # Intel App
./run-dev.command --build-only          # 只编译，不要求运行资源
./run-dev.command                      # 开发运行
./run-dev.command x86_64                # Intel 开发运行
./launch.command                       # 打开本机架构的已有 App
```

默认构建 Apple Silicon；Intel Mac 双击入口会提供 Intel 选择。非交互调用通过架构参数明确选择，Intel 实机运行仍待验收。`--check` 会按需编译小型资源检查工具，不编译 App 或 helper，不解码动画。

SDK 能力按实际 SDK 自动选择，最低 SDK 14。`BAILONG_BUILD_PROFILE=full|glass|plain` 显式选择档位；full 需 SDK 27+，glass 需 SDK 26+。主程序与 helper 共用工具链。输出为 `dist/<VERSION>/<架构>/`，显式档位额外加 `<档位>/`；启动入口使用相同变量。旧 SDK／工具链完整兼容仍以实际编译为准。

编译不显示百分比；阶段、耗时对应实际命令。warning／error 连同上下文实时显示，阶段结束统计诊断行，退出时清理临时诊断，不保留日志文件。`--help`、`--check` 可直接用于终端；无参数 .command 启用终端菜单，可用 `BAILONG_INTERACTIVE=0` 关闭。

## 维护资源包

`resource-manifest.json` 的 runtime 是 App 必需文件，development 是素材工具及来源说明。动画从 catalog 的 playbackFile／file 收集。预检查、App 复制和 ZIP 打包共用清单；原始图片、修边副本与其他本地文件不自动进入 ZIP。

```sh
./scripts/package-resources.sh
```

只生成本地 ZIP，不构建 App、不上传、不覆盖已有同名 ZIP。包内包含 `DEV-ASSETS.md` 和 `RESOURCE-MANIFEST.json`；制作来源中的本工程绝对路径改成相对路径，本机原件保持不变。发布前核对资源版本、下载大小及 published 状态。素材发布仍需单独授权。

## 只有制作素材时才需要的工具

普通源码开发直接使用资源包。以下工具用于更换资源，不是首次构建的必经步骤。

### 角色动画

资源包按当前素材清单收集实际播放的透明 HEVC 文件；源码版本变化不代表素材变化。原始 WebM、透明 PNG 帧序列及修复中间副本不在此包中。

拥有对应透明 PNG 后，可使用 [原生素材工具](../Tools/NativeHEVC/README.md) 替换已支持的动作：以 AVAssetWriter 写入 ProRes 4444，再用系统 avconvert 编码 HEVC Alpha。当前工具用于已有 catalog 的局部替换，不是从空目录生成全部 35 段动画的通用工具。

### 应用图标

直接使用包内 `BailongPet.icns`。若要从自己的透明 PNG 生成：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/GenerateAppIcon/main.swift -o .build/resource-tools/GenerateAppIcon
.build/resource-tools/GenerateAppIcon /绝对路径/角色.png local-assets/custom-icon.iconset
/usr/bin/iconutil -c icns local-assets/custom-icon.iconset -o local-assets/BailongPet.icns
```

### 玻璃符号

包内已有两份 PDF，构建时直接复制。重新导出需要提供这些符号的 macOS 27 系统；工具不创建交互窗口：

```sh
mkdir -p .build/resource-tools
xcrun swiftc Tools/ExportGlassSymbols/main.swift -framework AppKit -o .build/resource-tools/ExportGlassSymbols
.build/resource-tools/ExportGlassSymbols local-assets/glass-symbols
```

### 音效与 OpenAI 标志

复制完整 `sounds/`，同时保留来源及现有许可文件；当前 `来源.txt` 记录点击音为程序合成。OpenAI 标志直接复用包内 `openai-logo.png`，无需开发者另行读取已安装的 Codex App。

角色素材来源、图标制作与组件说明见 [来源与架构](来源与架构.md)。资源包保留原有来源说明，不新增统一素材许可证。
